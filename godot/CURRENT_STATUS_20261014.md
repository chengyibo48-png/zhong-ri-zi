## 1. 夜景与动作

- 室内使用较轻的夜色混合，预照明陈设避免重复变暗；去除空白边缘后按房间家具尺寸绘制。
- 47 栋建筑在四季都有夜间呈现。春季采用已有夜间原画，其余三季采用对应季节原画与专用夜景着色器；没有把着色器结果登记为新的独立手绘图片。
- 加入工作陈设逐帧姿态和暂停/简化动画分支；自行车使用交替踩踏、车身动作和分层角色绘制。
- 125 张状态图已补齐；既有独立素材队列为 674/674。新画面检查需结合本轮最终日志，不代表所有复杂动作都已达到人工美术终审标准。

## 2. 游玩与设备

- 用户目标为 Windows 电脑、集显笔记本、安卓/iPhone 浏览器，以及安卓 APK。实体手柄不列为本轮交付条件。
- 提供真实 GPU 场景、触控移动、菜单、转屏暂停、连续运行及加速年度状态检查。
- 当前实际显卡仍为 RTX 3060 笔记本；手机浏览器为 Chromium 设备模拟。真实集显、安卓手机和 iPhone Safari 的性能与完整人工年度试玩仍需实机证据，模拟结果不替代这些项目。

## 3. 性能与资源

- 三个交互 HUD 的无条件逐帧刷新改为统一事件调度；移动时限频更新，静止时避免无条件查询。
- 交互候选在同一帧共用缓存，采集点发现限频；NPC 规则更新保留原有时间语义。
- 检查 2,853 个 PNG/SVG，美术导出过滤 510 个确定未引用文件，约 2.5 MiB；保留源文件。
- 不透明室内背景采用兼容 S3TC/ETC2 的导入设置。移动端另外建立独立纹理导入副本，以降低浏览器传输、APK 和显存负担，保留原画与图集尺寸。
- 手机采用 30 帧上限和横屏触控 HUD，集显采用 60 帧上限；帧上限不等于最低配置实测通过。
- 新增可保存的“自动 / 省电”画面模式，省电上限 30 帧；扩展 AMD 常见集显名称识别，并缓存网页设备判断。Windows 触屏电脑保持桌面布局。

## 4. 存档与迁移

- 源加载器已覆盖牧场、环境、采集、邻里、反馈、馆藏等原待审子系统；仍保留完整行为等价和深层原生档案审计的边界。
- 原生存档新增基础类型、有限数值和容器检查，在修改内存前拒绝危险输入；农地 care 是数值，动物 care 是字典，专项回归已纠正类型误判。
- 0.26.1 继续检查深层关键字段、品质索引与数量，保护导入回退文件，并统一读写 16 MiB/浮点附加记录 20,000 条的限制。可恢复的邻里/NPC 字段沿用安全归一化，保持旧记录与 Unicode 标识兼容。
- 存档 IO 与外观/反馈归一化已拆成独立模块，保持 GameState 既有入口、原子替换、备份和恢复语义。
- 网页 JSON 导入导出使用浏览器文件选择与下载，站点存档仍依赖 IndexedDB；建议跨端使用导出 JSON。
