# 种植系统优化：菜畦、田土与农事框架

2026-10-16。本轮修改的是 `D:\.codex\游戏2\godot` 原生主版本。原版浏览器代码保留为历史规则基准。

## 优先完成的画面

- **相邻土地连成菜畦。** 主田按六格一行、东坡按十二格一行，根据实际开垦状态连接；未开垦、撤垄或中间缺格会露出草地，并收回相邻畦端。行间保留原有通路，72 个操作坐标、碰撞和导航数据均未移动。
- **田土有层次。** 新增一张真实手绘土壤材质，以垄沟、受光畦肩、下沿阴影和渐淡外缘形成起伏；不再用悬在草地上的独立小梯形表现每格耕地。纹理启用 mipmap，减少拉远时的细碎闪动。
- **五类土质与实际田况对应。** 壤土、沙壤、黏土、腐殖土和水田使用克制的材质色差；水分决定土色、低水分裂纹和高水分的轻微反光；低肥力、休耕覆草与冬季畦边薄雪也来自实际状态。减弱动效会停用水面微动。
- **作物扎根于田垄。** 根部有接触阴影；套种作物真实画在主株旁侧；再生作物采收后保留成株阶段，不会重新缩成幼苗。继续使用项目已有的 28 套作物及病虫、萎蔫图像。
- **田况标记更安静。** 成熟菱形、缺水水滴缩小并靠近根部，减少遮挡及跨行误读；选中田块改用四角定位线，覆盖实际菜畦宽度。

## 种田框架与操作

- 农事簿增加今日田况、天气、距换季天数，以及作物搜索、当季和持有种子筛选。目标田号、播种、按田况照料和收获放在前面；播种推算与详细建议可展开查看。
- 播种前显示水肥正常时首收时间、是否跨入不适季、种子投入和基础售价减种钱。明确提示这不是保证收益，未计水肥、人工和实时行情。
- “按田况照料”只安排真正需要的补水、排水、护苗和拔草；病害使用草本护苗，单纯虫害可人工处理。材料预览显示真实存量，混合照料区分农事次数和田块数。仍然逐块步行、动作完成后结算，可随时取消，缺材料或体力则停止。
- 再生主作物：番茄、茄子、青椒约 3 个生长日；黄瓜、秋葵、韭菜约 2 个生长日。天气、水肥、土质等仍会影响实际日历时间。成熟时“留种并结束这茬”可腾地轮作；没有增加强制每日任务。
- **旧档已有植株维持原收获方式。** 再生只对本版新播的六类主作物启用。原生存档保存采摘次数和再生周期；兼容田床副本也保留这两个数值。

## 检查发现并修复的规则问题

| 问题 | 处理 |
| --- | --- |
| 旧式自动灌溉被计算但未实际补水 | 在跨日结算中接通补水，保留高温与台风时的储备限制 |
| 喷灌固定补到 65，未使用作物需水范围 | 按作物下限设置触发值与补水目标；水生作物补得更足，每块仍只扣一次储水 |
| 套种完全继承主作物的水分、品种和季节生长速度 | 使用套种自身需求、季节、品种速度，并记录自身照料和成熟天数 |
| 套种品质被主作物的普通种上限及晚收时间限制 | 使用套种自己的品种上限、适土和生长记录 |
| 提示中的品质不包含精心照料专长 | 实际收获、留种和世界提示共用同一品质计算 |
| 播种可传入无效品种或密度，批量包含休耕田 | 播种前统一验证，规划跳过不适用田地，失败不扣物资 |
| 材料预览读取当前选择而不是任务保存的种子 | 改为读取任务参数，避免预览与实际执行不一致 |
| 连续采摘可能被当成重新种植，或重复送种 | 同一植株只记一次轮作、只在首收自动留种 |

借鉴的是《星露谷物语》可理解的种前选择、采后再生、局部灌溉和农事反馈，而不是复制画面或照搬所有惩罚。保留本作的五类土质、可救回的植株、反季减速、轮作与乡村设定。参考：[作物机制](https://stardewvalleywiki.com/Crops)、[肥料机制](https://stardewvalleywiki.com/Fertilizer)。
