# v0.11 禾溪物产 · 一篮一账

本轮接续 v0.10 工具设施版，落实用户新追加的物品与经济专项要求。同项目聊天《优化方案》的完整建议已保存为《物品与经济系统优化方案.md》。原文是规划参考；实施选择以当前游戏已有规则和本轮用户请求为准。

## 进入与游玩

背包、储物柜、杂货店、卖出入口统一进入“一篮一账”。生活菜单新增“物产与经营”；老街竹匾和合作社货签可走近互动，合作社屋内也有经营入口。查看面板暂停游戏时间，买卖、摆摊、交订单和领款通过现有村路导航，到达柜台或合作社再结算；没有地图传送。

## 适配与实现

| 方向 | 本版行为 |
| --- | --- |
| 统一物品信息 | 按种子、鲜蔬谷果、鱼蛋奶肉、料理、加工物、农资、材料筛选；搜索名称，按名称、数量、价值、优先用食材排序。详情从真实菜谱/加工/工具材料生成来源与用途，并显示喜欢该物品的邻居。 |
| 整理与快捷取用 | 每页 18 类，六格常用篮保持玩家选择顺序，耗尽后不自动换位。同类继续自动堆叠；指定数量与品质存取，分类一键存余量或补足随身五份。 |
| 物品保护 | 可锁定整类物品，阻止现售、代销、摆摊、订单、食用、赠送和配方材料投入；存取仍允许。已投入畜舍料仓/生产设备的物料按原系统继续工作。 |
| 品质、新鲜度独立 | 四档品质存量分别显示，可单独出售珍品或保留高品质。食材仍以原厨房批次记录年龄，选定品质后从最老批次提取；新鲜度影响价值，品质不随陈放下降，食材不被删除。 |
| 仓储兼容 | 继续使用现有储物柜、阴凉食橱和粮仓保鲜/周转，不再建立重复仓库。移动时品质和年龄一起保存；制作仍用随身材料，界面明确说明。 |
| 稳定商店 | 基础物品长期供应；三张每日轮换货签，每种限五份，普通货架继续销售。购买数量与旧农资入口使用同一价格，乡传良种仍执行原有解锁条件。 |
| 价格可解释 | 当季作物 −4%，淡季 +8%；年景三年循环为平稳、+4%、−2%；每周赶集指定需求 +20%；每季第 12—15 日料理家宴需求 +10%。界面逐项显示当前原因，另列品质与新鲜度。 |
| 批量卖出和回购 | 售货篮最多 12 条，可选数量/品质；整篮到达后重新验证，任一不足或锁定则全部不扣。现售最近 30 笔留货签，两次睡醒后仍可回购；原价加 5% 保管费，至少一元。回购返还原品质并累计陈放年龄，不刷新食材。 |
| 三类交易选择 | 许婶柜台立即结算；摊位最多 12 份，需要最多 3 体力和 90 游戏分钟，主题匹配 +12%，普通陈列 +4%；合作社每批最多 99 份，交货锁价 +8%，隔日领取。 |
| 经营主题 | 晨炊小摊适合料理、蛋奶；山果茶摊适合山果、山茶、蜜酱、凉饮；农家干货适合加工品与谷豆。老街新增竹木货台，货物和待领标记随货单状态变化。 |
| 合作社与长线奖励 | 每周三张需求单：时令篮、邻里早餐、优质乡味礼盒。最低品质明确，普通品有稳定用途；固定基础价与品质加价再加订单奖励。无失约罚款。供货信用满 20 后，同时在途货单上限由四张升到八张。 |
| 在途与账本 | 手动领取结算，重复点击不会二次发钱；可撤回原货并保留品质及累计年龄。最近 80 笔交易流水显示现售、购买、回购、摆摊、代销、订单和撤单。已交货单不会因错过日期消失。 |

## 平衡与取舍

保留当前游戏的宽松携带容量，不引入重量、格数、堆叠三重限制，也不让旧档超载后丢失物品。常用篮属于物品详情快捷入口，原数字工具栏顺序不变。家具继续由营造库存管理，收藏物仍在旧物柜，避免与生产材料混装。

使用现有“元”，供货信用是进度，不是第二种可花费货币。没有新增大量代币、随机价格暴跌、复杂顾客议价或强制每日订单。摆摊采用主题、备货、时间和手动收款，没有完整顾客队列模拟。现有 NPC 心愿、礼物偏好、公共工程奖励继续保留。

为防止直接买入再转卖套利，普通购价不低于基础售价的 1.85 倍；旧价格更高时保持旧价。市场价格系数上限 1.6，再叠加最高摊位 1.12，普通商品仍低于购价。生产加工与有限周订单可以创造收益。买卖前以货架和渠道预览为准。

## 存档和代码

新增 economy.version = 1，保存保护、常用篮、信用、货签、在途单、每日限购、已完成订单和交易流水。仍使用原 v3 主存档和键；不改变已有资金、物品、品质、厨房队列、工具改良、田间设施和建筑工程。

- src/economy.js：库存拆分、保护、价格、销售渠道、回购、订单与迁移。
- src/economy-ui.js：物品、货架、渠道比较、合作和流水四页。
- src/economy-view.js：老街货台、货物与待领状态。
- tests/economy.test.cjs：27 项专项；独立成品总计 30 段内嵌脚本。

## 验证与边界

176 项规则测试通过（既有 149 项与新增 27 项）。经济专项覆盖指定品质存取、保护、回购和撤单守恒、买入卖出价差、三年价格组合、限购跨档、批量原子性、延迟结算、重复领取防护、两处经营点真实寻路、空背包 UI、存档拒绝坏数据及 225 天跨系统读写。

隔离开发存档浏览器实测两份珍品拆分存取、71 元现售、重载后 75 元原货回购；五份鲜奶代销隔日领取 106 元；晨炊摊三份鸡蛋按主题结算 52 元且只扣一次体力。正式旧玩家仅用于读取和展示，不注入验收资源。

资源检查验证无外部运行依赖、30 段脚本可编译、开发台不进入独立 HTML。本版仍为浏览器 Canvas 游戏；没有进行实体手柄、真实断网双击和长期真人经营平衡验收。

补充界面验收：390px 正式成品中，物品网格与详情宽度均不超过 310px，页面宽度保持 390px；小满旧档仍为春 3 日、180 元、25 份物品。窄屏背包按钮补充了明确的无障碍名称。
