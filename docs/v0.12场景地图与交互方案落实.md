# v0.12 · 禾溪行路手记

依据同项目聊天《优化方案》的“场景与地图管理系统”专项设计，原文保存在《场景与地图管理系统优化方案.md》。该方案提出的是设计选项；本轮以实际 Canvas 游戏结构和用户“连续村庄、禁止地区传送、每个交互必须有过程”的要求决定取舍。

## 地图与场景

| 设计方向 | 本版落实 |
| --- | --- |
| 场景管理 | 统一查询世界/室内的标识、名称、区域、边界和原门位置；保留一张 5760×2304 六区村庄及现有全部可进入屋舍。进入/离开要先做推门动作，再切换坐标空间并淡入。 |
| 多层地图 | 沿用地表、地表细节、农田/玩家建设、按脚底排序的角色与高物、覆盖范围、天气与照明的绘制层；碰撞和营造占地继续使用独立规则。没有把工程重写成另一套瓦片引擎。 |
| 状态保存 | 新增 atlas：走访记录、最多 12 个自定义标记、追踪目标、筛选层与小地图开关。旧存档自动补全；原生产、仓储、NPC、屋内返回点保留。尚未结算的动作不存为半成品，不扣材料。 |
| 摄像机 | 地区名称变更不再触发镜头瞬间重置；出入门才切换坐标空间。保留缩放、像素清晰度和世界边界限制。 |
| 碰撞和选择 | 路线预览复用游戏真实碰撞/寻路，全部屋舍路线逐段验证；面向最近目标优先，鼠标指定目标优先；NPC 近身轻度让位，但不会被挤过墙或把玩家堵在门口。 |
| 地图与小地图 | 新“行路手记”替换原全图页面；住宅、乡亲此刻、公共屋舍、成熟、缺水、家畜、今日采集、个人标记共九层（含全村）。支持搜索与地区过滤。小地图显示玩家朝向、视口、路线及目标，室内显示对应屋门。 |
| 导航 | 点击仅预览可通行路线、估计时间；点“沿这条路出发”才移动。屋内先走原门再到户外目标，不传送；记住目标后重载需要手动继续。障碍落点给出失败提示，不偷偷换到遥远空地。 |
| 探索 | 六区的足迹由实际到访累积，不设硬锁；自定义资源/风景标记可命名和擦除，采集、作物、动物与村民位置来自当前游戏状态。 |
| 性能 | 全图和小地图使用简化示意绘制，不再为了地图页面加载六区完整地表；地表缓存限制 4 块，物件缓存限制 300 项，仍按视口绘制。远处生产沿用每日/游戏时间数据推进。 |

## 交互：做完动作，再结算

新增 `actions.js` 的短动作序列和动作道具绘制，`app.js` 统一接入场景点、农事/牧场/小灶/营造队列及原来直接修改状态的界面按钮。

- 动作分准备、动手、收好三个阶段，常规约 0.7—2.2 秒。角色朝向目标，使用竹篮、物品、钱币、账页、水壶、水滴、种子、工具、碗与蒸汽等对应表现；进出门有推门与遮光过渡。
- 世界中的采集、收获、播种、浇水、照料、聊天、彩蛋、休息、钓鱼、设施与服务点，均先显示动作，再调用实际结果函数。批量任务每个目标分别完成动作后结算。
- 物品存取整理、保护和常用篮、食用、赠送、故事选择、领取邮件、布局应用、房间布置、工具专长、生活安排等原有直接操作也接入动作流程。规划、搜索、标签页、设置和工具选择属于界面操作，保留即时响应及按钮反馈。
- 原有实体交易与生产仍先寻路；背包整理、阅读记事及部分旧生活操作在当前角色身边表现。没有给所有旧生活按钮重新补写地点任务，不能把本轮描述为全行为物理搬运模拟。
- 动作进行时屏蔽重复提交和移动；Esc 或“停下”可取消当前动作及剩余队列。本次尚未完成的动作不扣资源、不发奖励；批量中先前已完成部分保留。
- 切到后台停止推进动作；加载/刷新保留上一次结算后的状态，不自动重放未完成操作。回调只在内存中，不能写入存档。规则最终核验失败不会绕过库存保护。
- 掌火的火候在按下起锅时固定，新增起锅表现不会改变玩家已选中的火候。

不采用传送点、季节强制封路、硬性探索迷雾、外部地图编辑器或重型区块资源下载。当前规模已有足够稳定的连续道路和像素绘制基础，强制改为相互传送的分图会违背用户要求。

## 验证

原 176 项回归全部通过；新增 25 项场景/动作专项通过，共 **201 项**。包括全部屋舍的逐段碰撞路径、屋内先出门、旧档迁移、失效目标、自定义标记约束、动态经营层、村民位置、镜头过区连续、动作延迟/取消/重复点击/后台暂停/重载/失败结算，以及 225 天联合模拟。

4174 独立开发档浏览器验收：推门与取消；背包分拣取消数量保持 20，完成后 19；实体交易取消钱币仍 5000，完成后 5021 且只有一张回购货签；收获前体力 100、完成后 99，成熟标记 6→5；批量第一格完成、第二格取消，剩余 5 格未收；地图命名标记保存/重载；进灶备料→掌火→起锅完成，珍品料理获得、体力 100→98；390px 地图页面无横向内容溢出。正式成品加载和截图另记在验收记录中。

独立 HTML 含 33 段内嵌脚本，通过编译与外部资源检查。真实断网双击、实体手柄和长时间低端设备性能未在本轮复验，不宣称相应实测结果。
