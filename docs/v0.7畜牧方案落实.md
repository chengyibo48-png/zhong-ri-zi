# v0.7 · 东坡牧场

实施依据：同项目聊天《优化方案》的《畜牧养殖系统深度优化思路》，原文见《畜牧养殖系统优化方案.md》。本轮按用户“落实到游戏”的要求实施。

## 进入方式

生活菜单 → **牧场名册**。在动物身边可以查看、添料、抚摸。村庄地图中可以步行前往东坡鸡鸭舍、东坡牧舍、东坡羊圈、东坡猪圈；四种畜舍均可入内。羊圈与猪圈需要修缮后才能安置伙伴。

## 本版明确取舍

- 延续原项目温馨风格，不实现死亡、屠宰或皮革肉类生产；猪采用圈肥与放牧拱菌，交易通过可接回的送养完成。
- 坐骑属于原方案可选扩展，本版继续使用已有自行车；没有新增骑乘或运输负重系统。
- 牧草采用两片自然恢复的草甸；背包干草可由菜叶晾成，没有另增一种占用农田的牧草作物。
- 畜舍使用固定村庄位置，按容量与工位升级；未加入自由搬迁整座畜舍或玩家绘制任意牧区边界。
- 宠物沿用原有单个猫/狗伙伴，不新增多宠同时饲养与宠物品种收集。
- 繁育以数个“舒适日”为周期，不模拟真实月份；高温、寒潮与台风缺少保温舒适设施时会延缓。

## 存档与测试

旧存档自动补全牧场记录，保留伙伴名字、亲近、待收产物、背包、田地、钱币和村庄位置。动态动物、品质库存、繁育、送养与料仓均写入同一存档。载入校验会拒绝非法数量、重复动物 ID、畜舍错配等损坏数据。

自动化检查：原有 59 项回归 + 新增 22 项养殖专项，共 **81 项通过**。包含连续 225 天养殖与种植存取、自动化真实消耗、品质防重领、繁育预留、疾病恢复、所有新门口与 72 块田的可达性。

浏览器验收：独立开发端口实测两只羊批量喂食扣 4 份饲料、剪毛保留品质、次日幼崽出生、寻路进羊圈抚摸幼崽、从羊圈出门再到猪圈购买成年猪。390px 窄屏名册无横向内容溢出。正式端口原有“小满、春三日、180 元、25 件背包”进度可正常读取。

单文件成品内嵌 18 个脚本，通过语法及无外部资源检查。浏览器以 HTTP 直接载入该单文件；本轮不将此等同于实际断网/file:// 启动测试。
