# 更新记录

## v0.4.0 · 2026-09-26

- 按当代南方乡村和 2D 像素基线重做人物、房屋、植被、动物及生活道具；24 位村民有独立形象与画像册。
- 五张地图各扩大到 1920×1152，新增果园、荷塘、稻田、学校、卫生室、邮政点、竹编屋、梯田与望村亭等 26 个交互地点。
- 默认画面物体约放大 20%，保留全屏、跟随镜头、全部模块内置；加入区域全图、地点带路和遮挡淡化。
- 旧档坐标只迁移一次，外围坐标可保存；导入时修复被景物卡住的位置；新版采集点状态和区域压力正确持久化。
- 调整 24 个家具位置以留出道路，修正窄屏生活簿的尺寸约束与焦点滚动。
- 35 项规则和地图检查通过；完成五区域实机观察、荷塘钓鱼、农田采收、刷新/手动读档及 390×844 大字号验收。
- 美术仍为项目内代码绘制；单文件通过构建检查，实际离线启动与实体手柄仍需目标设备复验。

## v0.3.0 · 2026-09-26

- 重新核对原方案和首发预算，扩展为 24 位村民、28 种作物、30 道菜及 6 种厨房工序。
- 加入 84 个个人故事节点，8 条成年关系线各含五节、恋爱选择、婚礼和婚后独立生活。
- 加入四季章节、四场节庆、四项共同工程、八个院落节点、家具制作布置与个性化年度回顾。
- 补齐品质仓储、试做与替代食材、便当、四类技能/工具、水利天气、照料动物、猫狗、来信互助和收藏。
- 保留全屏和全部功能内置，新增文字/对比/音频细分设置、标准手柄控制与季节音景。
- 升级版本 3 存档并兼容 v1/v2，修复品质转移和家宴读档后重复邀请，隔离开发调试界面。
- 29 项逻辑测试、225 天读写模拟和真实旧档迁移通过；完成新内容 UI 和窄屏验收。实体手柄与本版实际离线运行尚待目标设备复验。
- 增加逐项落实表、112 天内容 CSV、资源 SHA-256 清单和可重建独立包。
