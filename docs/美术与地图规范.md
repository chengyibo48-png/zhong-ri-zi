# 美术与地图规范 · v0.4

项目沿用温暖、写实、当代南方乡村的 2D 像素方向。所有美术由本地 Canvas 绘制，不引用外部图片和字体资源。

## 画面与尺度

五区均 1920×1152；旧中心布局平移 (480,288)，外围增加手工布置的生活空间。镜头按 800×480 基准覆盖窗口，禁用图片平滑，不拉伸比例；原生全屏仍由用户按钮触发。地图页绘制 960×576 区域缩略图。

世界人物约 32 逻辑像素，四向形象及步态复用基础结构；画像设计画布 64×80，在画册以更高画布分辨率绘制。用轮廓、发型、工作服和随身道具识别职业，避免仅靠名字标签。人物定义位于 src/art.js 的 styles。

## 村庄细节

屋顶有瓦列、屋脊、檐下阴影；房屋有木门、门把、春联、窗格、台阶与墙根。保留空调、太阳能热水器、自行车、邮政点等当代线索。植物以层叠树冠、枝干、树根阴影表现体积，四季替换明暗色。荷塘使用不规则岸线、水色、芦苇和荷叶。晒匾、竹篮、陶罐、晾衣、茶桌与小石磨补充生活痕迹。

避免把所有地面填满：保留田间道路与休息草坪，前院布置格避开中央通行线。五区是固定设计，不扩展成程序化无限地图。

## 渲染与交互

静态地表按区域/季节缓存，道具缓存并按可见范围裁剪；人物和物体按脚底排序。屋檐、树冠遮到主角时减淡。互动提示在附近显示，贴身时用统一 E 提示。

landscape.js 同时定义视觉和阻挡；16 像素网格寻路，整段路径不得穿建筑/水域。所有新增地点需要加入可达性验证。版本 3 存档用 worldRevision:2 表示新版坐标，不重复平移旧档。不要为美术变更清空用户进度。

## 后续质量空间

人物和物体已提高辨识度，但依然是代码像素绘制版本；可继续精修个别头像五官、职业专属动作、剧情镜头与天气音景。新增资产应遵守现有比例、四季色板和碰撞约束。
