# 物品与道具图标系统优化思路

物品图标会出现在背包、快捷栏、商店、配方、任务、地图提示、仓库和收获反馈中。它既要让玩家一眼认出物品，也要帮助玩家理解物品的类别、品质、状态和用途。

当前工作区没有可读取的项目文件，我无法确认游戏现有的像素尺寸、调色板、界面缩放或已完成图标。下面按你规划的种植、畜牧、加工烹饪、建设、工具、采集和钓鱼系统来设计，实际规格需要与项目现有 UI 和美术规范统一。

## 一、先建立统一的图标视觉规范

正式扩充图标前，先约定图标系统的基础规则：

- 图标画布尺寸、透明边距和主体占比。
- 像素描边、阴影、高光和视角方向。
- 每类物品的主色倾向和识别特征。
- 是否允许背景底板、稀有度边框或角标。
- 在背包、快捷栏、商店和弹窗中的缩放规则。
- 透明背景与不同 UI 底色上的可读性。

如果游戏采用像素美术，图标应沿用场景的像素密度和色彩风格。缩小时要保持轮廓清晰，避免过细的装饰、文字和高光细节在小尺寸下糊成色块。

## 二、图标应表达的不只是物品名称

玩家在背包中看到图标时，最好能从外形或辅助标记推断：

- 这是什么东西。
- 属于哪个类别。
- 是否可以使用、出售、加工或交付。
- 是否有品质、新鲜度、耐久或任务属性。
- 是否是当前配方或任务需要的物品。

图标不必独自承担全部信息。建议让物品主体表达“是什么”，少量角标或边框表达“当前状态”，详细用途由物品详情和文字说明补足。

## 三、物品类别与识别规则

### 1. 农作物、采集品与种子

作物图标要区分食用形态、种子形态和加工前原料：

- 成熟作物突出可识别的果实或蔬菜外形。
- 种子使用独立的小袋、种粒或叶片符号，避免与可食用产物混淆。
- 野果、蘑菇、竹笋、草药等采集品尽量体现其生长形态或采集环境。
- 同类不同品种优先通过颜色、轮廓和叶片形状区分，而不是只换一处小色点。

### 2. 动物产出

鸡蛋、牛奶、羊毛、蜂蜜等图标应简洁且主体明确。若品质或新鲜度不同，可以通过角标或边框显示，不要为每种状态都重新绘制完全独立的图标。

### 3. 工具与装备

工具图标需要在小尺寸下看清轮廓：

- 锄头、斧头、镐、镰刀、水壶等最好使用稳定的方向和比例。
- 工具升级后可以通过材质、颜色或柄部装饰体现等级。
- 装备与普通制作材料应使用不同的视觉构图。
- 耐久不足时可以显示状态条、裂纹角标或低耐久标记，避免整张图标变暗导致难以辨认。

### 4. 料理与加工品

料理可以体现成品形状和制作方式：

- 汤品使用碗、液面或蒸汽轮廓。
- 烘焙品用外形和烤色区分。
- 腌制品、酒和饮料使用不同容器。
- 奶酪、果酱、干货和面粉等应让玩家能看出加工后的形态。
- 同一基础食谱的变体可以保留主体轮廓，通过配料、颜色或小装饰区分。

### 5. 建筑材料、家具和任务物品

木材、石材、零件等材料应和可摆放家具区分开。建筑与家具图标最好呈现其完整形状；材料图标则适合使用堆叠、切面或原料形态。

任务和奖励物品可以有统一标识，例如任务角标、信封、星标或专属边框，但不能让任务标记遮住物品主体。

## 四、品质、稀有度与物品状态

### 1. 品质显示

可沿用普通、优质、上品、珍品等级，统一使用边框、角标或简短标记。建议：

- 基础图标始终保持相同，品质通过外围表现区分。
- 不只用颜色区分等级，还配合形状、图案或文字标签。
- 高品质效果不能遮住物品本体。
- 品质在背包、商店、任务和收获反馈中保持一致。

### 2. 新鲜度与耐久

新鲜度和耐久都是会变化的状态，不适合给每个数值做一份单独图标。可以采用：

- 新鲜度：小型计时或叶片状态标识。
- 临近变质：轻微褪色、边缘提示或明确文字。
- 工具耐久：耐久条或损坏状态角标。
- 过期或损坏：保留物品轮廓，额外显示不可使用状态。

状态提示需要适度。玩家浏览大批库存时，满屏闪动和颜色变化会造成干扰。

### 3. 叠加数量

堆叠数量适合显示在图标角落，并保证低数量和三位数数量都能读清。空堆叠、满堆叠和不可堆叠物品应有统一表现，避免数量文字与品质角标互相遮挡。

## 五、工具、装备与升级图标

工具图标不仅要识别类别，也应支持升级系统：

- 初级、进阶和高级工具沿用相同轮廓，使用材质与细节表现等级。
- 功能分支用明确的小标记区分，例如范围型、精准型或耐久型。
- 装备中的工具可以增加选中框或快捷栏状态。
- 未解锁工具可以显示剪影和解锁条件，不一定展示全部细节。
- 工具与配方材料不要使用相似的轮廓，减少背包误用。

如果支持主角穿戴或更换装备，装备栏应使用比普通背包图标更大的展示尺寸，方便看出外观差异。

## 六、任务与奖励图标

任务图标要突出“这是目标或奖励”，并与物品类别区分：

- 任务物品可显示统一任务标记。
- 当前追踪目标可以在角标或背景上高亮。
- 任务奖励可以显示金币、代币、配方、家具或声望等类型。
- 任务完成后显示完成态，但保留物品主体。
- 限时活动或季节任务可以加主题符号。

任务图标与普通物品图标应共享绘画风格，但不要使用完全相同的框架，以免玩家误以为它们可以正常出售或消耗。

## 七、图标在不同界面中的使用

### 背包

支持按种植、材料、食材、工具、家具、任务等分类筛选；详情面板显示用途、来源、售价和可制作配方。图标状态要能让玩家快速找到临近变质、任务需要或可升级的物品。

### 快捷栏

快捷栏图标需要在小尺寸下仍清楚识别，当前选中状态应明显。工具、食物和消耗品可以使用不同数量或耐久显示方式，但角标位置要统一。

### 商店与交易

商品图标旁应能同时看清售价、收购价、品质和库存数量。当前价格上升或下降等市场信息不应覆盖商品主体，可以单独放在价格区域。

### 配方和加工设备

配方页需要显示原料是否足够、缺少数量和可替代材料。缺料状态可以变暗或加数量提示，但最好保留物品外形，方便玩家辨认并去仓库寻找。

### 收获与通知

一次收获多种物品时，可以显示图标加数量；同类物品短时间内合并成一条结果。珍品、新发现或新配方可以使用更醒目的独立反馈。

## 八、图标和可玩性的结合

### 1. 图鉴发现

新鱼、新作物、稀有资源或特殊料理第一次获得时，可以展示图标解锁动画，并提示图鉴已更新。玩家能把收集目标和物品视觉对应起来。

### 2. 来源与用途线索

物品详情页可以展示：

- 来自哪个地区、季节或天气。
- 可在哪些设备加工。
- 可用于哪些食谱、建设或订单。
- NPC 是否偏好该物品。
- 是否适合留种、放流或修复生态。

图标负责快速识别，详情负责规划用途。这样物品不只是背包中的图案，也能帮助玩家决定如何经营。

### 3. 节庆与季节主题

限时活动可以给既有物品增加节庆包装或背景角标，而不是复制出大量视觉相同的新物品。活动结束后，玩家仍能在图鉴或收藏页面查看曾获得的特别版本。

## 九、资源制作与维护流程

为了让图标数量扩展后仍容易管理，建议统一资源组织规则：

- 按物品类别存放图标。
- 使用稳定的物品 ID，而不是只依赖本地化名称。
- 保存基础图标、状态标记和品质边框的对应关系。
- 记录物品图标尺寸、透明区域和导出方式。
- 维护“物品数据—图标文件—图鉴条目—配方用途”的对应表。
- 为未完成、缺失或重复图标提供可检查列表。

可以先完成一批代表性图标，放进实际背包、商店和配方界面中缩放检查，再确定完整批次的绘制规范。只在放大画布上确认好看不够，必须检查游戏实际显示尺寸。

## 十、需要避免的问题

- **类别靠颜色区分，色弱玩家难辨认**：同时使用轮廓、图案或文字标签。
- **同类物品只换一个颜色点**：至少改变主体形状、叶片、容器或配件之一。
- **角标太多，主体被遮住**：限制品质、任务、新鲜度等标记的同时显示数量。
- **每种状态都复制一份图标**：优先使用可组合的状态覆盖层。
- **高品质图标过度发光**：避免让稀有度效果影响轮廓识别。
- **图标和场景物件不一致**：农场中的作物、动物产出、鱼类和加工品应与库存图标保持同一造型逻辑。
- **扩大图标数量却不完善搜索**：图标、分类、标签、排序和详情应一起设计。
- **任务物品被误卖**：通过任务标识、锁定功能和出售提示保护重要物品。

## 十一、推荐实施顺序

后续进入制作或开发时，可以按以下顺序推进：

1. **定义图标规范**：尺寸、风格、描边、色彩、边距和状态标记。
2. **建立物品清单与分类**：把种植、畜牧、加工、建设、采集、钓鱼和任务物品统一编号。
3. **绘制基础高频图标**：基础作物、常见产物、工具、材料、金币和料理。
4. **接入实际 UI 检查**：在背包、快捷栏、商店、配方和通知中验证可读性。
5. **增加品质与状态标记**：处理品质、新鲜度、耐久、任务锁定和数量。
6. **补充稀有和季节内容**：特殊鱼、限定种子、节庆料理、收藏物品。
7. **完善图鉴和物品详情**：连接来源、用途、配方和 NPC 偏好。
8. **持续检查一致性**：确保图标、场景资源、名称、分类和交易数据对应。

建议先做一套小而完整的试验组，覆盖作物、动物产物、工具、料理、材料和任务奖励，并放入真实 UI 验证。确认缩小后依旧能认清，再批量扩充，会比一次性画出大量图标后返工更省力。
