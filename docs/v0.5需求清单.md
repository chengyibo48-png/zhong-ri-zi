# v0.5 本轮用户要求与验收基线

1. 24 位 NPC 均有专属住处，按日程真实行走、休息、回家。
2. 村庄全部房屋可入内；按主人性格与职业布置，至少三处各有内容的小彩蛋，动作反馈可见。
3. 扩大可耕作面积和牧场，增加照料、探索与生活交互；填充空地时有实际用途。
4. 五区域合为一张连续乡村，地图标出所有住处；地图只能导航，禁止区域传送。
5. 明显的雨雪雾、日出日落、夜色、室内暖灯和随时段变化的阴影。
6. 日常以场景动作、粒子、短气泡和环境变化反馈；长对话和管理页面作为补充。
7. 画面更清晰、人物和物体更有层次；逐项完成测试、实机观察和交付。以具体实现衡量变化，不宣称无法客观测量的“十倍”质量。

这份记录保存用户本轮明确要求，覆盖前版本独立场景与地图传送方案。沿用全屏、全部模块内置、当代中国田园与旧档兼容。
