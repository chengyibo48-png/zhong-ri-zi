# v0.19 物品与道具图标方案落实

日期：2026-09-28。依据：优化方案聊天中的《物品与道具图标系统优化思路》，原文归档为同目录同名 Markdown。原文“当前没有项目文件”是当时的背景描述，本轮已以实际源码核对。

## 实际实现

| 方案方向 | 本版实现 |
| --- | --- |
| 统一规格与资源身份 | 32×32 透明图标，以物品 ID 为入口；关闭平滑缩放，在 32 / 48 / 64 / 96 像素界面使用同一绘制定义。浏览器将基础图形缓存成 32 像素画布，最多 224 项；未知 ID 有可见占位。 |
| 全部物品覆盖 | 覆盖现有 190 种物品。补绘豆荚、叶菜、根茎、谷穗、青椒、野果等；沿用并统一接入仍适用的旧图案和 v0.18 五类鱼获。190 个绘制定义非空、无完全相同绘制记录；不宣称全部 190 张均从零重画。 |
| 种子与产物区分 | 28 种作物的三类种子袋显示对应作物，普通袋、左侧乡传封签、右侧节令封签区分品种。底部当前种子入口同步显示实际选择的种子袋。 |
| 畜产与加工品 | 鸡鸭蛋及受精蛋、羊毛团、毛线、毛呢、羽毛、奶油杯、酸奶罐、奶酪、面粉、油瓶、米酿、果酱、干货与茶盘分别绘制。 |
| 料理辨识 | 汤品、叶包米粽、面条、糕点、布丁、奶香饼、腌菜坛和饮品采用不同容器或成品形态；盘碗中的主要配料复用原料图形。修复四种糕点原本重复的问题。 |
| 工具与奖励 | 工具图标读取真实改良等级，图录可查看当前六种农具；心愿回礼使用金币和实际物品图标。保留现有工具材质升级，不虚构不存在的装备栏或工具耐久。 |
| 状态分层 | 背包/储物柜以菱形数量和品质文字表达单一品质；混合堆叠明确写“混合品质”。保护锁与宜先用提示位于物品主体外，数量仍独立显示。锁定优先占用第二个标记位，新鲜度文字仍在原详情中保留。 |
| 配方识别 | 材料不足时保留原物品外形，并明确显示“缺 N 份”，不只依赖变色。 |
| 来源与用途 | 菜单新增“禾溪物品图录”：按名称/类别搜索、24 项分页、已收录/尚未获得、32 像素与大图对照、来源、加工/料理用途、NPC 偏好及随身/储物数量。种子详情明确适种季节、良种购入条件及节令种暖棚限制。 |
| 无扰动接入 | 图录预览全部图标，但不自动解锁图鉴、配方或赠送物品；不改售价、品质规则、库存容量或存档结构。沿用原动作后结算与锁定保护流程。 |

## 使用与维护

入口：Tab → 禾溪物品图录。背包、仓库、货架、配料、成熟作物和收获展示共用 ZRZWorld.item。状态标签由真实库存、品质批次、锁定和陈放数据产生；没有另建一份状态副本。

- src/item-icons.js：ID 映射、基础图形、缓存、物品状态描述。
- src/item-icons-ui.js：图录与标签；src/economy-ui.js 接入背包和仓库；src/kitchen-ui.js 接入缺料数字。
- docs/物品图标清单.csv：190 项 ID、名称、类别、绘制家族、来源及用途。
- tests/item-icons.test.cjs：16 项图标专项检查。

保留单机、全屏、模块内置、隐藏小地图与连续村庄地图。家具继续使用既有场景模型和营造预览；本轮没有新增节庆包装收藏玩法、独立装备经济或工具损坏规则。

## 验收证据

原有 401 项测试与新增图标测试通过，共 417 项。执行整套回归后，对最后补充的种子来源说明再次运行全部 16 项图标测试。覆盖全部物品的非空绘制、有限坐标、种子品种、加工前后差异、混合品质、储物柜品质、陈放、锁定和图录不修改游戏数据。

55 个正式版内嵌脚本编译通过；独立 HTML 无远程资源、外部运行文件及开发入口。浏览器实测图录分类与名称筛选、加工品图案、种子三种封签、背包锁定动作及生效、料理缺料数字、390×844 布局。正式版原有小满存档仍为春05、180元、87体力、41件物品；控制台没有错误。
