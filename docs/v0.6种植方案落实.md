# v0.6 四时农事：种植方案落实与验收

日期：2026-09-27。依据：同项目聊天《优化方案》的《种植系统深度优化方案》（原文保存为“种植系统优化方案.md”），以及本聊天“将项目中的种植系统优化方案落实到游戏中去”的实施授权。

## 怎么玩

- 生活菜单 → 农田照料，打开“禾溪 · 四时农事”；站在田边也可点“查看这块田”。
- 72 块田共用连续村庄：01—24 为稻香小院，25—72 为东坡。点索引只查看；“走到田边”和农事操作都会沿路步行。
- 按成熟、缺水、风险、待播、区域和作物筛选，批量操作先预览，再逐块执行。方向键、点地面、打开菜单或停止带路可取消；耗尽体力/材料会停止，保留已完成部分。
- Q 打开种子袋：选择作物、普通/乡传良种/节令种、疏植/标准/密植，记住选择后拿起种子袋。密植用两份种子，以更高养分与病虫压力换取潜在额外产量。
- 详情里可查看预计成熟时间、水土、健康、病虫草、季节、设施、轮作建议、产量品质与留种预览。
- “田埂设施”可建造、搬动、修理、暂停设施，显示覆盖线；竹管喷灌有水分阈值与 120 格储水，每次给一块有作物的田补水用一格。
- 成熟后前三天为最佳采收期；第 4—8 天、健康达到 75 的作物专门留种多一份。晚收仍可采收，健康良好的上品可选出乡传良种。

## 对照方案

| 方案部分 | 实际实现 |
| --- | --- |
| 1 整体循环 | 规划—开垦—播种—照料—成熟/留种—轮作/养地，全部连接真实库存、体力、时间和存档 |
| 2 地块管理 | 荒地、松土、种植、板结、休耕、撤去田垄与修复；有作物时禁止直接撤除，保护收成 |
| 3 土壤三属性 | 壤土/沙壤土/黏土/腐殖土/水田土，0—100 肥力和水分；保留肥沃/稳定/待养护的简明分档 |
| 4 生长 | 种子、萌芽、幼苗、生长、开花结实、成熟、留种期、可抢救萎蔫；天气、水分、肥力、密度、病虫与设施影响速度 |
| 5 病虫害 | 虫害与叶斑分开计量；连作、密植同科、湿热、弱土增加压力，较重邻田小范围传播；人工、草本和速效三种治理 |
| 6 四档品质 | 普通/优质/上品/珍品，售价 ×1/1.2/1.4/1.7；持续条件均值定品质，保留种子上限；存取、出售、吃饭、送礼消耗不复制品质 |
| 6 品质用途 | 高品质食材改善料理/加工结果；最高收获品质收藏；优质留种。基础菜谱和原有订单仍接受普通品质 |
| 7 农事动作 | 开垦、深耕、三种密度播种、浇水/过浇、排水、熟堆肥、缓释肥、豆种绿肥、除草、三种护苗、收获和留种 |
| 8 轮作/套种/立体 | 同科连作加压、豆类与休耕养地；邻田兼容关系；每垄一个副作物独立生长和采收；瓜豆攀架、叶菜微荫 |
| 9 种子 | 全 28 种作物各有普通、乡传良种、节令种，共 84 种种子；速度、抗虫与品质上限有取舍；手动和自动留种 |
| 10 设施 | 喷灌、暖棚、稻草人、遮阳、矮篱、攀架、排水共 7 类；局部范围、材料资金、每田埂两座、耐久、维修、搬动与开关 |
| 11 天气 | 三日预报；雨水补水与涝害、高温蒸发、寒潮减速、台风积水和设施损耗；各自有应对手段 |
| 12 信息反馈 | 农事总览计数、72 田块索引、图标与文字、三项状态条、生长阶段、建议、季节/设施及收成预览 |
| 13 减负 | 按区域/作物/状态批量浇水、施肥、播种、收获；角色实际走到田边，逐块执行；局部阈值自动灌溉 |
| 14 平衡 | 失照不会清空作物，风险能抢救，土地能修复；普通品质保持基础经济和任务可用 |
| 15 实施顺序 | 上述基础、养护、风险、长期经营、设施、批量六层在本版连通 |

## 为原项目节奏保留的边界

原方案中的污染、盐渍化、永久死亡、雨水冲毁地块属于可选风险举例，本版用缺水、积水、板结、肥力下降、杂草与可抢救萎蔫表达风险，没有加入永久死亡、农地永久损失、氮磷钾化学模拟或强制品质任务。围栏使用田埂覆盖保护，未增加自由绘制闭合围栏和动物逐只碰撞破坏。套种采用一主一副与邻田关系，未制作自由拖动多层种植架。以上为可玩的规则实现范围，不把这些未实现的模拟形式宣称为已完成。

## 兼容与修复

- 存档主版本仍是 3，种植数据单独带 farm.version=1；旧 24/72 田块档补齐水土，不清空已有作物、物品、关系、工程和房屋位置。
- 已有蓄水升级赠配局部喷灌和满箱储水；旧档的已摆放菜架、篱笆、稻草人、暖棚在容量允许时迁到最近田埂。装饰外观保留。
- 新建田埂设施可消耗同类已有家具库存；庭院布置页明确景观与农田设施的用途，移除“稻草人治虫”等旧说明。
- 品质数组从两项兼容扩至三项，修复吃饭/送礼/拆分/存取对珍品的消耗与重复统计问题。
- 加工队列保存输出品质，雨天顺延不会重复发品质；普通库存优先消耗时不会冒充高品质用料。
- 保留锄头、水壶升级的省力效果。
- 修复高面板侧栏固定后导致批量按钮无法滚入可点击区域的问题。

## 验证记录

- 原有 44 项回归测试 + 15 项种植测试，共 59 项通过，涵盖旧档迁移、密植扣种、季节限制、水分、局部设施、四档品质、加工、轮作、套种、确定性病虫、抢救、批量筛选与资源不足中止、损坏存档及 225 天跨季保存。
- 浏览器独立开发端口实测：4 块成熟田逐块采收，收获 +8、体力 -8；4 块空地批量播种乡传良种，种子 30→26、体力再 -8。正式端口与开发验收档隔离。
- 浏览器实测暖棚建造扣款 220 元、木料 10、竹材 12，耐久 100，覆盖 4 块田；搬往 3 号田成功，未重复建造。
- 1280 宽屏农事界面已截图检查；390 像素窄屏 DOM 验证 modal-body clientWidth/scrollWidth 均为 350，无横向溢出。
- 单文件构建内嵌 15 个脚本，不含开发检查台入口；所有脚本可解析，无远程素材或运行时依赖。
- 本版单文件通过 HTTP 成品加载验证；浏览器禁止 file:// 导航，未声称已实际断网启动。
