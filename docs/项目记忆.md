## 不可变方向

《种日子》是一款单人单机 2D 像素生活养成游戏。城市返乡青年继承爷爷的老院，以一年时间修缮家园、重新认识邻里、选择未来生活。背景是当代南方乡村，写实、温暖、松弛。叙事是弱主线、强日常，无救世危机、阴谋、穿越或魔法。

三条体验支柱：农事有时令；饭桌连邻里；共同劳作改变村庄。经济、技能、土壤等系统应服务这三个体验，而不制造每日负担。

正式版固定 112 天、四季各 28 天。五区域：农家小院、隔壁集镇、后院竹林、村口河流、远处野山。完整首发 24 位村民：8 位成年可攻略角色（4 男 4 女）、12 位主要支持村民、4 位儿童或青少年。未成年人绝不进入攻略系统。攻略不限制主角性别。8 条关系线含婚后生活，不能留待更新补齐。

## 体验规则

1. 农事有季节、浇水、生长与收成反馈，少量品质档；土壤只有肥沃、稳定、需要养护三档可读状态。轮作有小奖励，不模拟氮磷钾，不强迫作物序列。
2. 鸡鸭牛先做深，每只动物有名字、性格、亲近度、稳定产物。漏喂只短期影响产量，不生病死亡、走失或被野兽袭击。
3. 料理连接自用、便当、待客、节庆、送礼与订单。工序短，支持批量，优先家常菜的实际用途。
4. 关系阶段少而清晰。交谈、协作、送菜、节庆都有效；不每日衰减，不因错礼或拒绝请求永久扣分。NPC 会回礼和主动互助。事件可延后和补救。
5. 公共项目需要乡亲共同参与；完成后有场景、活动或对话变化，不只发钱。
6. 体力不是生命值。耗尽后休息或暂停劳动，不晕倒、不掉物、不晚起。
7. 对话、背包、日历、烹饪、装修暂停时间；舒缓/常规两档速度。预测天气至少提前一天。
8. 重要信息可从日历、地图、作物提示、村民位置、手记查看。错过非主线日期不破坏结局。
9. 全年结尾回顾生活选择，不按财富或全收集给单一优劣评级。可继续来年经营。

## 明确排除

不做战斗、矿洞、怪物、地牢、武器、生命值、伤害和战斗死亡；不做矿石资源链。无多人联机、创意工坊、赛季通行证、线上日常运营、移动端移植承诺、程序化大地图、复杂病虫害、随机永久损失、动物屠宰或强生态惩罚。第二年新剧情、额外区域、子女完整成长都不属于当前首发承诺。

## 技术与阶段

采用数据与逻辑分离、集中时间状态、事件标记、带版本的存档。当前浏览器原型无运行依赖，美术由 Canvas 生成，音效由 Web Audio 合成。所有玩法使用同一 state，不另建重复的日期/货币/关系状态。

阶段顺序：范围冻结 → 最小闭环 → 7–14 天垂直切片 → 系统扩展 → 四季内容量产 → Alpha 全流程和平衡 → 发布构建。v0.3 已进入系统扩展和全季内容联调阶段；短篇文字场景可运行，但不等同完成商业演出与正式发行质量。

后续质量重点：真人第一周与完整年度节奏、角色对白润色、像素演出和音频听感、实体手柄及目标浏览器兼容。24 人角色表与八条五节点关系线已经实现。保留五区域、四季闭环和关系内容承诺，内容压力大时先减少重复物品和装饰变体。
