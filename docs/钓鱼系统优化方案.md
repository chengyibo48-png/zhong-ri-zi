# 钓鱼系统深度优化思路

钓鱼可以提供与种植、畜牧不同的节奏：玩家寻找合适水域和时机，通过操作技巧获得鱼获，再决定将鱼用于料理、加工、订单、赠礼或收藏。

建议把钓鱼做成一条完整循环：

> 选择水域与时机 → 准备钓竿和鱼饵 → 抛竿等待 → 判断咬钩信号 → 与鱼周旋并收杆 → 处理鱼获 → 记录图鉴或投入经营。

玩法深度主要来自**地点、季节、天气、装备和操作选择**，而不是单纯增加鱼种数量或让 QTE 越来越难。

## 一、水域体系与地图差异

水域需要在资源、环境和操作体验上有所区别。除了河流、湖泊、池塘和深山溪谷，还可以按项目地图加入海岸、地下水域、农场水塘等类型。

| 水域 | 环境特点 | 适合的鱼类或玩法 |
|---|---|---|
| 河流 | 水流较快，鱼群可能沿岸移动 | 适合中小型鱼、洄游鱼，抛竿位置和水流方向有影响 |
| 湖泊 | 水域开阔，鱼种较多，深度变化明显 | 适合多种鱼类，远投或不同水层可以增加差异 |
| 池塘 | 面积较小，鱼群容易观察 | 适合入门钓鱼，也可与农场建设结合 |
| 深山溪谷 | 水温较低、环境安静，季节影响明显 | 适合冷水鱼、稀有鱼和探索奖励 |
| 海岸或河口 | 若地图中存在，可作为后期区域 | 适合大型鱼、洄游鱼和特殊渔具 |
| 农场水塘 | 玩家可建造或改造，受农场生态影响 | 可养殖、放流、观察鱼群，提供稳定但有限的鱼获 |

### 水域不只靠鱼种区分

不同地点还可以有不同的：

- 水深与可抛投区域。
- 水流、岸边障碍和可站立位置。
- 鱼群活跃时间和移动范围。
- 季节、温度、天气带来的变化。
- 钓鱼时的视野、音效和等待节奏。

例如河流中的鱼会顺流移动，湖泊可以分成岸边、浅水和深水区域，池塘容易判断鱼群但稀有种类较少。差异应当让玩家换地点有理由，而不是只换背景图。

## 二、鱼类体系与生态条件

每条鱼可以由一组生态条件定义：

- 出现水域。
- 出现季节或温度范围。
- 活跃时段。
- 天气偏好。
- 偏好的水层和鱼饵。
- 体型、拉力和耐力。
- 稀有度与出现概率。
- 是否洄游、成群或对噪声敏感。
- 鱼获品质上限与用途。

### 鱼类分类

可以从常见、中级、稀有和季节限定几个层次组织：

- **普通鱼**：稳定出现，适合入门、料理和基础出售。
- **水域专属鱼**：只有特定地点或生态条件下出现。
- **季节鱼**：特定季节或水温时出现。
- **稀有鱼**：需要正确地点、鱼饵、时机或较高技巧。
- **特殊鱼**：剧情、探索、传闻或节庆相关。
- **养殖鱼**：通过农场水塘或特定设施繁殖、管理和收获。

每条鱼都应有自己的行为特征，而不是只换名称、售价和 QTE 难度。例如：

- **谨慎型**：咬钩信号短，偏好安静水域。
- **冲刺型**：上钩后快速变向，考验收线节奏。
- **耐力型**：速度不快，但会长时间消耗鱼线张力。
- **底栖型**：偏好深水和沉底鱼饵。
- **群游型**：一段时间内连续出现，适合批量垂钓。
- **雨后活跃型**：降雨后更容易靠近水面。

## 三、鱼群和水域活跃度

为了让钓鱼能读懂环境，可以将鱼群活跃度作为水域的轻量状态：

- 鱼群可能因季节、时间、天气和近期钓获变化。
- 同一地点连续垂钓后，短时间内鱼群活跃度下降。
- 更换水域或等待恢复后，鱼群重新活跃。
- 观察水面波纹、鱼影、飞虫或鸟类活动，可以推测鱼群位置。
- 鱼群进入活跃期时，可能出现连续咬钩或稀有鱼机会。

不要让玩家必须每天轮换路线才能钓到基础鱼。活跃度主要提供额外效率和发现感，普通鱼始终应有稳定的获取方式。

## 四、钓鱼操作流程

### 1. 选择位置与抛竿

抛竿可以根据目标水域和装备体现差异：

- 玩家选择大致落点，而不是必须精确像素瞄准。
- 抛到鱼影、水草、深水或水流汇合处可能提高对应鱼类出现机会。
- 钓竿等级影响可抛距离、可抛区域或操作容错。
- 岸边障碍、树枝和桥梁形成位置限制，提示原因即可，不应频繁让玩家因看不见的判定失败。

入门阶段可以采用简单方向选择或范围预览；后期装备再解锁精细抛投，不要把基础钓鱼做成高难度瞄准练习。

### 2. 等待与咬钩提示

等待阶段可以通过水面和声音提示反馈：

- 轻微波纹：鱼群经过或鱼在试探。
- 浮漂晃动：鱼正在接近。
- 明确下沉或铃声：可以提竿。
- 特定声音或视觉线索：可能对应大型或稀有鱼。

咬钩信号要有清楚的早期提示和成功窗口。高级钓竿、鱼漂或鱼饵可以扩大提示窗口，但不应让新手无法判断何时操作。

### 3. 鱼的行为阶段

上钩后的过程可以用简洁状态表现：

1. **试探或起跑**：鱼向某方向拉动。
2. **挣扎**：鱼会冲刺、停顿、变向或下潜。
3. **疲劳**：拉力减弱，进入更安全的收线窗口。
4. **收杆**：成功拉近并捕获，或鱼线断裂、鱼逃走。

行为可以按鱼类特征改变，不需要每条鱼有完全不同的小游戏，但应让玩家从拉力和方向中感受到区别。

### 4. 收杆与张力控制

如果采用 QTE 或拉力机制，建议核心反馈由鱼线张力组成：

- 收线太快：张力升高，鱼线有断裂风险。
- 及时放线：降低张力，但鱼可能游远。
- 鱼疲劳时收线：效率更高。
- 使用合适鱼竿和鱼线：提升安全范围和容错。
- 玩家连续正确操作：更快让鱼进入疲劳状态。

屏幕应显示清晰的张力区域、鱼的方向和当前建议动作。失败后应明确提示是拉力过高、收线过慢，还是鱼线等级不足。

## 五、不同操作强度与无障碍选项

钓鱼不一定所有玩家都喜欢高强度反应操作。可以提供不同模式：

- **轻松模式**：提示窗口更长，张力变化缓慢，适合体验和收集。
- **标准模式**：保留判断咬钩和控制张力的操作。
- **精细模式**：鱼会改变方向和节奏，操作表现可提高品质或获得额外鱼获。
- **辅助功能**：降低 QTE 频率、自动处理连续按键、放大提示或提供视觉/声音替代。

高难度适合奖励额外收益、荣誉或收集记录，不应成为获取剧情关键鱼和基础料理材料的唯一方式。对于项目实际输入方式，可以再决定使用按键、鼠标、手柄还是触屏交互。

## 六、渔具升级与鱼饵系统

### 1. 钓竿与渔具

装备可以分成几类，每类解决不同问题：

- **钓竿**：影响抛投距离、鱼线张力范围和收线能力。
- **鱼线**：影响承受拉力和大型鱼捕获能力。
- **鱼钩**：影响特定体型鱼类的上钩表现。
- **鱼漂**：改善咬钩提示或延长反应窗口。
- **渔轮**：加快回收或降低收线时的张力。
- **网兜**：增加成功收获机会或改善大型鱼收杆容错。
- **鱼篓**：增加可携带鱼获数量，但不应改变钓鱼技巧本身。

装备升级适合分成**功能等级**与**品质表现**：

- 等级解锁新能力，例如抛到更深水域、挂载特殊鱼饵。
- 品质提高稳定性、耐用度或少量容错。

钓竿不应该全面提升所有参数。可以有轻便型、强韧型、精准型和远投型，让玩家按水域和目标选择。

### 2. 鱼饵功能

鱼饵可以有明确分类：

- **通用饵**：容易获得，能钓常见鱼。
- **昆虫饵**：吸引特定淡水鱼或雨后活跃鱼。
- **植物饵**：偏向草食性、底栖或小型鱼。
- **加工诱饵**：通过料理或加工获得，适合特定稀有鱼。
- **季节鱼饵**：季节限定，扩大某类鱼的出现机会。

鱼饵可以影响目标鱼群、咬钩速度或鱼类范围，但尽量不要保证必出某条稀有鱼。玩家需要准备鱼饵，也需要观察水域。

### 3. 鱼饵获取与制作

鱼饵可以来自商店、采集、昆虫捕捉、加工或制作。这样采集系统和烹饪加工系统都能参与钓鱼准备，但基础鱼饵仍应稳定购买，避免缺少某种材料就完全不能钓鱼。

## 七、鱼获品质、尺寸与状态

鱼获结果可以包含几个不同维度：

- **鱼种**：决定主要用途和基础价值。
- **体型**：影响重量、尺寸纪录或料理分量。
- **品质**：影响售价、料理效果或展示价值。
- **新鲜度**：影响料理效果、加工结果和售价。
- **捕获状态**：例如是否完整、是否适合放流或展示。

鱼获品质可沿用普通、优质、上品、珍品。品质可以受到：

- 钓鱼操作表现。
- 鱼类健康与环境状态。
- 使用的渔具和鱼饵。
- 鱼获体型或稀有属性。
- 捕获后处理和保存方式。

品质不应完全取决于 QTE 表现。即使玩家操作一般，也能获得普通鱼获用于食用、出售或制作基础料理。

## 八、鱼获用途和系统联动

鱼不只用于卖钱，可以连接多条玩法：

- **料理**：恢复体力、提供抗寒、抗热或探索增益。
- **加工**：腌制、烘干、制成鱼干、鱼油或其他加工品。
- **动物饲料**：特定鱼类可用于宠物或畜牧饲料。
- **订单**：餐馆、村民或合作社订购特定鱼种、尺寸或品质。
- **赠礼**：不同 NPC 有喜欢的鱼类或料理。
- **收藏**：图鉴记录鱼种、体型纪录和发现地点。
- **生态管理**：特定鱼类可以放流到农场池塘或帮助恢复水域。
- **展示与竞赛**：稀有大鱼参加节庆展览或钓鱼活动。

部分鱼获可以支持“出售、食用、加工或放流”的选择。放流可能改善水域生态、提高后续鱼群活跃度，或解锁保护成就；它应是额外选择，而不是强制损失收入。

## 九、季节、天气与一天中的时段

天气系统可以让钓鱼更有规划价值：

- 雨天某些鱼靠近水面或河岸。
- 大雨后河流水速加快，适合部分鱼类，也可能降低能见度。
- 雾天某些鱼类更大胆，但位置更难判断。
- 寒潮让鱼类活动变慢，需调整鱼饵或水层。
- 晴天适合寻找水面鱼影或日间鱼种。
- 不同季节改变鱼群种类、体型和活动时段。

时间条件应以可观察的提示呈现，例如“傍晚活动”“雨后活跃”，避免让玩家靠外部攻略才能理解。季节限定鱼可以每年再次出现，也可以通过旅行商人、鱼卵或交换获得，不要因错过一次就永久错失。

## 十、鱼类图鉴、研究与发现

图鉴可以是长期钓鱼目标，但不应只是捕获数量清单：

- 记录鱼种、地点、季节、天气、鱼饵和体型。
- 发现新鱼后补充生态描述和烹饪用途。
- 连续观察可以发现鱼群偏好或迁徙规律。
- 特定鱼种的研究记录可解锁配方、鱼饵或区域情报。
- 个人最佳纪录和农场展示柜可以承载收藏成就。
- NPC 渔夫或研究者可以通过对话给出模糊线索。

图鉴奖励适合提供知识和新选择，而不是永久提高所有鱼获概率。让玩家逐渐成为“懂得观察水域的人”，比单纯累计捕获次数更有成就感。

## 十一、农场水塘与鱼类养殖

如果农场建设系统支持池塘，可以把池塘设为钓鱼玩法的延伸：

- 玩家通过修建池塘获得稳定、有限的钓鱼地点。
- 放流鱼种后经过时间繁殖或成长。
- 水质、季节和饲料影响鱼群健康。
- 池塘可用于观赏、养殖、收获或教学。
- 不同鱼种可能相互竞争，或需要不同水深和水质。
- 玩家可以选择留鱼维持种群，或定期收获。

池塘适合提供便利和经营选择，不应完全替代野外探索。稀有水域鱼、迁徙鱼和特殊天气鱼仍然需要外出寻找。

## 十二、经济与难度平衡

- 常见鱼提供稳定但有限的收入和料理材料。
- 稀有鱼更适合订单、收藏和特殊料理，不应成为唯一高效赚钱方式。
- 大型鱼需要装备准备，但可通过技巧和合理准备战胜。
- 鱼饵成本与鱼获收益要平衡，避免钓鱼变成稳定无限印钞。
- 鱼获新鲜度可以推动及时处理，但保质期应足够宽松。
- 高品质和纪录奖励可以是额外收益，不要让普通鱼失去价值。
- 失败通常消耗时间或鱼饵即可，不应频繁损坏昂贵装备。

## 十三、界面与反馈重点

钓鱼界面应优先显示玩家当下需要的信息：

- 当前水域、时间和天气提示。
- 可用钓竿、鱼线和鱼饵。
- 抛投点或水层提示。
- 咬钩信号。
- 鱼的方向、拉力和耐力状态。
- 当前成功捕获概率的定性提示。
- 背包空间和鱼获保存状态。
- 捕获后显示鱼种、体型、品质、用途和图鉴进度。

失败反馈要具体，例如“鱼线张力过高”“鱼饵不适合当前水域”“鱼群已暂时离开”，这样玩家知道下一次可以调整什么。

## 十四、推荐实施顺序

后续进入开发时可以分阶段推进：

1. **基础钓鱼循环**：选择水域、抛竿、咬钩、收杆和获得鱼获。
2. **鱼类数据与图鉴**：加入水域、季节、天气、时间和行为标签。
3. **渔具与鱼饵**：让装备和鱼饵产生清晰但不过度复杂的差异。
4. **品质与用途**：连接料理、加工、交易、订单和收藏。
5. **生态与水域活跃度**：加入鱼群变化、连续垂钓影响和季节迁移。
6. **农场池塘**：接入建设、放流、养殖和持续收获。
7. **特殊事件与竞赛**：加入天气限定鱼、传闻鱼、节庆赛事和稀有纪录。

第一阶段先把钓鱼操作做得清楚、稳定、有反馈，再加入鱼种生态、经济用途和水域管理。这样钓鱼既能成为独立的休闲玩法，也能自然融入农场生产与探索。
