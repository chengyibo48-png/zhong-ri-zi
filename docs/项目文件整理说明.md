# 项目文件整理说明

整理日期：2026-09-27。游戏版本：v0.16.0。

## 保留内容

- `src/`：所有游戏源码及开发检查台。
- `tests/`：完整规则测试、浏览器验收脚本和旧存档兼容性样本。
- `docs/`：原始方案文字、各系统优化方案、落实说明、项目记忆与验收记录。
- `docs/验收图/`：v0.16 三张验收图，以及 v0.17 春日小景和冬夜灯光两张关键验收图。
- `.git/`：完整本地提交历史，可恢复各历史版本源码；没有删除版本历史。
- `种日子.html`：可直接游玩的独立成品。
- `index.html`、`style.css`、构建和本地服务器脚本：开发运行所需文件。
- `资源与构建清单.json`：版本、依赖和文件校验记录。

`index.html` 是开发入口，`种日子.html` 是独立成品，两者用途不同。旧存档样本与测试不是重复游戏存档，均保留。

## 清理范围

检查正式源码、测试、脚本和文档的 SHA-256，没有发现内容完全相同的重复文件。

已移除原 `qa/` 中 197 个临时文件：一次性代码补丁脚本、过时参考副本、重复测试日志、样式草稿和历次验收截图；其中本版 3 张关键验收图已先复制校验并保留到上述正式文档目录。历史文档中的旧 `qa/...` 路径作为当时验收记录保留，相关临时图片本次不再留存。

历史发布 ZIP 不作为运行依赖。完整项目包校验成功后清理这些旧 ZIP，只保留一份整理后的完整包；源码历史由 `.git/` 保留。

## 存档说明

游玩存档保存在浏览器中，不在项目目录里；本次文件清理不会删除浏览器数据。继续使用原来的 `http://127.0.0.1:4173/种日子.html` 地址可沿用该地址的存档。更换浏览器或使用不同地址前，请从游戏内导出 JSON 存档。
