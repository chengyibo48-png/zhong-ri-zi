# v0.15 · 邻里作息与对话

日期：2026-09-27。已重新阅读项目原始方案，并对照同项目《优化方案》中的 NPC 基础系统与对话系统专项。专项原文归档为 `NPC基础与对话系统优化方案.md`；原文中的建议按现有连续村庄和存档结构取舍，作为产品设计参考。

## 方案与实际实现

| 方案重点 | 本版实现 |
| --- | --- |
| 人物身份、性格和目标 | 24 位已有居民各有独立性格、生活目标、工作动作、两条家常对白、信任对白、实用窍门和一件可参与的小事。保留 8 位成年候选人、12 位支持居民、4 位儿童的边界。 |
| 可理解的日常作息 | 面点师早起、成人到各自工作地、孩子平日去小学、午间回家、傍晚探访亲友、夜间归屋。每周赶集与节庆调整去处；恶劣天气优先留在自己的屋内。行踪簿解释变化原因。 |
| NPC 是生活中的人 | 居民沿可通行路线移动，进出屋经过同一门口。屋内走到家具旁停留；增加看书、揉面、整理、编织、敲打、浇水、拍照、饮茶、观鱼等动作。靠近或参与互动时停步并面向玩家。 |
| 村民有自己的事情 | 每日最多新增两份小事，覆盖全体居民。接受、明确改天、送两份指定材料或共同劳动均可选择；没有期限和拒绝惩罚。共同劳动花 20 游戏分钟、3 体力；完成关系 +6，仅一次；完成后至少 28 天才可能再次提出。 |
| 有实际用途的材料和过程 | 相册需要米浆、旧凳需要木料、观察牌需要竹撑等，逐人解释用途。共同劳动使用各自的整理、阅读、修补、烹制等动作；不是只点一次文字就立刻结算。 |
| 对话随情境变化 | 优先考虑可继续的个人故事、生日节庆和当前约定，再结合真实鱼获、采集、公共修缮、亲密程度、天气、季节与日常。保留最近 12 个话题以轮换内容；不凭空生成共同回忆。 |
| 分支与关系记忆 | 继续沿用原有个人故事与明确恋爱选择；记录实际选择、礼物和帮助方式。“说起一起经历的事”引用真实已完成经历，儿童没有恋爱入口。 |
| 对话表现 | 走近、停步、招手或翻阅后再展示对话。画像与场景角色有平静、认真、思考、开心的表情反馈。看对话时游戏时间暂停。 |
| 可查询、不强迫刷聊天 | 新增“禾溪邻里簿”，按人物、关键词和类别查询最近 160 条交流。相同人物同日同一内容只收一条，永久故事回看仍保留在原故事页。窍门可主动请教，关键条件仍在对应系统手记中查看。 |
| 旧档和系统兼容 | 新字段 `neighbors` 自动补齐，不改已有经济、农牧、厨房、房屋、关系或故事进度；继续沿用 v4 存档和原存储键。载入校验人物、日期、数量上限和小事状态，拒绝损坏字段。 |

## 入口与操作

生活菜单、地图、邻里、日历或故事页底部 → **禾溪邻里簿**。选择“沿路去找对方”后，按 E 或点击角色交谈。对话内可选“聊聊此刻／说点家常／请教生活窍门／说起一起经历的事”，也可承诺帮忙、参与劳动、送材料及回看交流。

所有会改变邻里状态的操作要面对面执行。完成动作后才结算；Esc 或“停下”取消未完成部分。没有隔空送礼、远程完成个人故事或未做动作直接拿奖励。重复聊天不会重复领取当日关系奖励、回赠或菜谱。

## 验证

- 15 组测试共 **331 项通过**，其中 NPC 专项 35 项。涵盖 24 人作息目标通路、进出屋连续运动、恶劣天气与节日优先级、每日奖励上限、接受/推迟/供料/劳动、取消与重复保护、实际故事和礼物记录、旧档及 225 天联合读写。
- 浏览器开发档实测：E 招手后打开对话；接受后仍未完成；劳动取消体力保持 100、小事保持 accepted；完整劳动后体力 97、关系仅加 6；故事实际选择进入记录；关键字“名单”只筛出相应分支。刷新后任务、体力、故事和对话记录保留。
- 材料分支实测：回赠后稻米 10，送材料后为 8，体力保持 100，记录 method=supply，不能重复完成。
- 390×844 对话记录页没有横向页面溢出；最终恢复浏览器默认视口。实机诊断及控制台没有游戏错误。验收图在本地 `qa/v15-history.png`、`qa/v15-dialogue.png`，不混入发布包。
- 成品由 45 段内嵌脚本组成；正式版不含开发检查台，不依赖远程资源。实际断网双击与实体手柄本轮没有复验。

## 本轮取舍

把方案的“轻量生活事件”落实为可长期保留的居民小事，避免随机事件要求当天赶场。沿用现有 24 位村民与亲友关系，不额外加入旅行商人、游客、永久迁入迁出、疾病惩罚或复杂婚后家庭模拟。公共工作日程目前表现为建筑附近的工作与可见动作；住家内活动和进出门均实际模拟。对话采用可验证的手写内容和条件选择，不接入在线生成服务。

代码：`src/npc-content.js`（人物内容）、`src/npc.js`（规则与存档）、`src/npc-view.js`（工作与神情）、`src/npc-ui.js`（对话和邻里簿）。
