# v0.8 · 禾溪小灶与四季食记

依据：同项目聊天《优化方案》中的「加工与烹饪系统深度优化思路」（本地保留全文），以及原始方案 3.3、扩展清单 C。用户本轮明确要求实现，原方案聊天的「先不修改」属于当时讨论阶段，不阻止本轮落实。仍保持南方田园、无战斗、连续村庄、全部模块在游戏内。

## 实际入口与操作

生活簿 → 菜谱 / 家常加工。六页为灶边菜谱、乡间工序、等待的味道、食橱保鲜、自由试配、工位改良。制作、投料、收取、清洗、改良与试配会让角色沿村路走到禾溪小灶，再走近对应器具；方向键、点地面、打开菜单可取消，抵达前不扣食材。跨区没有传送。

| 方案要求 | 本版实际落地 |
| --- | --- |
| 设备体系 | 柴火灶、蒸笼、石磨、木梁榨油机、腌菜缸、烘干架、米酿桶、乳品架、蜜酱锅、堆肥篓共 10 个实体工位；对应室内像素器具、烟气与完工提示 |

| 实际等待与收取 | 磨粉 45、榨油 90、焙茶 20、奶油 45、果酱 100 游戏分钟；晒制/腌制/酸奶约 1 天，米酿/奶酪约 2 天；成品留工位，需手动收取 |
| 清洁与升级 | 投料、做饭降低清洁；低于 30 时品质上限优质，可擦洗恢复。两级升级增加容量、队列和后续速度，每级耗时缩短 15%；工位不会永久损坏 |
| 固定菜谱 | 保留 30 道既有菜，新增荠菜春笋羹、山果凉饮、南瓜奶香饼、芝麻暖奶，共 34 道；保留 NPC 传授、赶集购买、节令学习与替代食材 |
| 自由研发 | 两样原料带谷香、鲜香、奶香、清香、甘甜、田园标签。匹配固定配方则领会、保留原料；其他搭配各用一份，产出可食用田园汤，记录最近 40 个组合并可复做 |
| 手动与快捷 | 快做、批量、手动火候可选；火候指针 35—75 为宽容成功区，加一档品质；偏离仍产出家常菜；可省心制作，关闭不扣料 |
| 四档品质 | 普通/优质/上品/珍品接通背包、存储、交易；按本次实际消耗的原料品质、新鲜度、火候、熟练、工位等级、应季情况计算；陈放材料和脏工位限制上限 |
| 新鲜度与保存 | 每种食材分批记录数量与陈放年龄；新鲜/尚可/宜先用/陈放。鲜奶鱼虾 5 日、料理通常 7 日、蔬菜等通常 12 日、干粮 21 日、腌干酿酱油 28 日 |
| 温和后果 | 陈放不删除、仍可加工与食用；售价最低七成，基础回复最低约 65%；不添加疾病、死亡或整仓腐烂 |
| 储藏 | 普通柜半速陈放；150 元和竹材 6 添阴凉食橱，柜中降至四分之一速度；存取保留原有年龄与品质，不能通过来回倒仓刷新 |
| 料理效果 | 品质每档额外回复 3 体力；饱足和暖胃让劳动少耗 1，轻快让步行速度增加 12%，180 游戏分钟；有增益的新食物替换旧增益，不无限叠加 |

## 存档与衔接

仍为 v3，新增 `kitchen.version:1`，原存储键不变。旧档原料按新鲜批次迁入，不追溯惩罚。原 `processing` 工序继续原规则自动入包；本轮新工序进入 `kitchen.jobs`，记录时间、工位、品质、数量，手动领取一次。牧场奶油、酸奶按钮改走小灶；原毛线、布料、饲料、圈肥手作保留。

背包的品质沿用既有普通优先、低档到高档消耗规则；陈放账按最旧批次先扣。两个账本分别保证数量守恒，不声称逐个实物具备可单独选择的品质/年龄标签。成品在工位等待时保持封存，收取才计算保鲜；这是温和节奏的明确取舍。

## 没有照搬的可选想法

不加入肉类屠宰、生命值、战斗抗性、设备毁坏、苛刻限时、不确定抽奖式试错。自由研发目前是有标签的双食材发现与可食用变体，不是任意槽位化学模拟；米酿/乳品使用明确熟成周期，未添加多段陈酿或蒸馏。没有工业自动产线，新工序仍需投料和收取，批量快捷承担减负功能。未另加蜂群、盐糖作物或复杂副产品库存。

## 验证

103 项测试通过：81 项既有回归 + 22 项厨房专项。专项包括材料与金钱原子性、四档品质、批量替代、串并行队列、重复收取、清洁升级、雨天顺延、跨季限制、批次年龄、存取保鲜、旧档迁移、脏数据拒绝、旧工序接续、料理增益替换/到期，以及 225 天农牧厨房联合存取循环。

浏览器实际验收：进入小灶、走近掌火与出锅、石磨投料、重载后待收与收取、奶果试配手札、临期奶提示、390px 单列排版与批量做 3 份饭。开发夹具用独立 4174 端口；正式存档不注入测试物资。

成品由 21 段脚本内嵌，零远程资源、零运行依赖，独立 HTML 通过 HTTP 加载验证。本轮未重复实际断网和 file:// 浏览器启动测试。
