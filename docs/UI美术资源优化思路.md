# UI 美术资源深度优化思路

UI 美术资源不只是面板、按钮和字体素材，而是玩家理解农场状态、找到操作入口、感受到季节与经营成长的视觉系统。种植、畜牧、加工、建设、交易、天气、采集、钓鱼和 NPC 对话都需要使用相同的界面语言，避免每个功能看起来像独立拼装的菜单。

当前工作区没有可读取的项目文件，因此我看不到现有 UI 截图、字体、图标、配色或画面比例。以下先按前面规划的农场经营玩法设计方向；具体像素尺寸、分辨率和素材格式应在看到项目现有界面后再确定。

## 一、建立统一的 UI 美术方向

建议先确定一套可贯穿整个游戏的视觉基调，再制作具体素材。可以考虑**温暖、手作、带有农场生活质感**的方向：面板像农场日志或木质公告板，按钮像标签和印章，装饰借用种子袋、叶片、麻绳、工具和木纹等元素。

整体风格要适应场景，而不是每个界面都大量加入农具图案。可以按界面用途调整：

- 农场日常界面保持轻巧，不挡住地图。
- 背包和仓库强调清楚的分类与数量。
- 商店、合作社使用价格标签、货箱和订单纸的视觉线索。
- 天气和地图页面使用更清楚的信息图形。
- 对话界面留出角色表情与文本空间。
- 设置、存档等系统菜单减少装饰，突出易读性。

统一规则应覆盖面板边角、按钮形状、描边、阴影、颜色、图标尺寸、字体层级和动效节奏。

## 二、面板与边框资源

### 1. 面板类型

不必为每个菜单单独画一整套图。可以先建立基础面板组件，再组合不同装饰和布局：

- **轻量面板**：物品提示、操作说明、角色状态。
- **标准面板**：背包、商店、任务、配方、建筑目录。
- **大型面板**：地图、百科、农场总览和系统设置。
- **剧情面板**：对话、重要事件、角色关系场景。
- **确认面板**：拆除建筑、出售稀有物品、放弃任务等关键决定。

同一底板可以改变标题栏、角饰和纹样来表现不同用途，减少资源制作量并保持一致。

### 2. 面板外观与实际内容

如果采用像素风格，可以用木板、纸张、布料、金属牌或种子袋等材质作为局部点缀。边框设计要控制厚度和装饰密度，避免缩放后占用太多内容空间。

每个面板应明确区分：

- 标题与关闭区域。
- 当前分类和选中状态。
- 内容主体。
- 操作说明和快捷键。
- 重要状态或风险提示。

玩家需要优先看见内容和按钮，装饰应当围绕信息服务。

## 三、按钮与控件资源

### 1. 按钮状态

按钮至少应有：

- 默认状态。
- 鼠标悬停或手柄选中状态。
- 按下状态。
- 不可用状态。
- 当前选中或切换开启状态。
- 正在处理或等待状态。

这些状态不能只靠颜色区分。可以用轻微位移、边框、阴影、图标或亮度变化共同表达。

### 2. 不同功能的按钮层级

- **主操作**：播种、确认购买、提交订单、开始加工。
- **次操作**：查看详情、切换分类、返回上一步。
- **危险操作**：拆除、丢弃、放弃任务。
- **开关控件**：自动喂食、天气提示、音效选项。
- **数量控件**：出售数量、制作数量、材料分配。
- **筛选控件**：品质、类别、来源和状态。

危险操作可以使用更明显的警示样式，但不要让所有“取消”按钮都呈现错误或失败的感觉。

### 3. 操作设备适配

如果游戏支持键盘鼠标和手柄，按钮需要同时显示实际输入提示：

- 鼠标操作时显示鼠标图标或点击提示。
- 手柄操作时显示对应按键。
- 操作设备切换后及时更新提示。
- 当前焦点要足够明显，尤其在库存格、配方列表和对话选项中。

## 四、图标与符号系统

UI 图标需要和之前讨论的物品图标使用同一套美术语言，但用途要区分。

### 1. 通用功能图标

建议为以下功能建立可复用符号：

- 背包、仓库、工具、地图、日志。
- 金币、特殊代币、订单和商店。
- 种植、动物、加工、料理和建设。
- 天气、季节、时间和区域。
- 好感、健康、饱食、心情和新鲜度。
- 任务、提醒、未读信息和危险状态。

图标要能在小尺寸下辨认。复杂含义应配文字标签或悬停说明，不要要求玩家单凭抽象符号猜功能。

### 2. 状态图标

状态标记可以在不同界面复用，例如：

- 缺水或积水。
- 动物饥饿、生病或心情低落。
- 加工设备缺少材料或已经完成。
- 新鲜度下降或工具耐久不足。
- 订单临近截止。
- NPC 有新事件或可交互内容。

同一状态在背包、总览和地图上应使用一致图形，避免玩家记住多套符号。

## 五、字体与文字层级

字体需要兼顾风格与长时间阅读。农场题材可以使用有手写感的标题字体，但说明、价格、数量和任务要求应使用清晰、字形稳定的正文体系。

建议至少划分：

- 标题字体。
- 正文与说明字体。
- 数字和价格显示。
- 手写标签或便条样式字体。
- 强调、警告和成功状态的字效。

文字层级要稳定，例如标题大于栏目名，栏目名大于说明，说明大于辅助提示。金额、倒计时、数量等高频信息需要容易扫读；不要为了氛围给所有文字都加描边、阴影或倾斜效果。

### 多语言与内容长度

如果游戏会支持不同语言，UI 资源需要留出扩展空间：

- 面板和按钮不能只按中文短词设计。
- 长任务名称和多行说明需要有换行方案。
- 数字、日期、货币格式要适应不同显示宽度。
- 字体缺少某些字形时要有备用字体。
- 文字不能贴边或被装饰遮挡。

## 六、装饰元素与农场主题表达

装饰可以让 UI 有温度，但最好承担一点信息或氛围作用，而不是堆在所有面板上。

可用的元素包括：

- 木纹、缝线、纸张边缘、邮戳、夹子和绳结。
- 叶片、谷穗、花朵、果实和季节纹样。
- 工具轮廓、木箱、瓶罐、布袋和标签。
- 小动物脚印、羽毛、鱼鳞或蜂蜜滴等类别符号。
- 节庆旗帜、雪花、落叶和春季花纹。

装饰可以随季节、节庆、房屋扩建或玩家选择的界面主题变化。例如春季面板带新芽，秋季订单页出现谷穗和果实；这种变化能与天气和农场成长呼应。但核心信息框架应保持稳定，让玩家不用每季重新学习 UI。

## 七、与游戏系统相连的界面风格

### 背包与仓库

重点是网格清楚、数量易读、分类明显。品质、新鲜度、任务锁定和堆叠数量不要互相覆盖。选中物品后，详情面板显示用途、售价、配方和来源。

### 种植与畜牧

地块总览、动物状态和风险提醒可以使用清晰的图标、短标签和条形状态。农场的视觉风格可以是手绘记事或田园图鉴，但关键状态不能只用装饰性插画表达。

### 加工与烹饪

加工面板可采用配方卡、材料槽、完成时间和产物预览。设备状态可以通过运行图标、进度标记和成品提示表现。料理成品展示需要留出空间表达品质和效果。

### 建设与布局编辑

建造界面要显示建筑图样、成本、占地和覆盖范围。放置预览用清晰的可放置、不可放置状态；移动或拆除操作要能区分回收材料和不可恢复部分。

### 天气与地图

天气图标和地图符号应简洁，适合不同屏幕尺寸。农场总览可以使用可切换信息层，例如灌溉、成熟作物、动物所在区域和设施覆盖范围，不要一次把所有标记都叠在地图上。

### NPC 对话

对话框要让位给角色肖像和表情。选项按钮应清楚区分当前焦点与不同选择，重要承诺可以附简短说明。日常对话可以轻量显示，关键剧情再使用更完整的边框和背景演出。

## 八、创意方向：让 UI 像农场自己的工具

### 农场手账主题

把部分系统信息呈现成玩家的经营手账：每日收获、天气预报、待办事项、NPC 来信和农场目标可以像便签或剪贴页一样组织。

### 季节性 UI 小变化

季节可以改变少量边缘装饰、背景色和角标图案，但不改变功能布局。玩家看到季节变化会有新鲜感，同时不会因换肤而找不到按钮。

### 玩家自定义主题

可以通过扩建房屋或任务奖励解锁少量 UI 主题，例如原木、花园、蓝白瓷或节庆风格。主题只改变面板外观和装饰，不影响信息对比度、按钮位置和操作规则。

### 经营成就徽章

农场发展、料理、钓鱼和社区贡献可以获得小型徽章，展示在农场日志、个人档案或房屋展示墙中。徽章既能作为视觉奖励，也能回顾玩家的经营路线。

## 九、可读性与无障碍

- 保证正文和背景有足够对比度。
- 状态不只依赖颜色区分，同时使用形状、文字或图案。
- 提供字号、对话速度和提示持续时间选项。
- 减少闪烁、弹跳和高亮动画，提供关闭选项。
- 重要通知同时提供视觉与声音反馈，但不强制依赖声音。
- 避免装饰纹理穿过正文区域。
- 手柄选中状态、键盘焦点和触屏反馈需要明显。
- 面板打开后，焦点顺序符合玩家预期。

## 十、资源制作与维护流程

UI 资源越多，越需要组件化管理。建议统一记录：

- 面板类型、尺寸和九宫格或拉伸规则。
- 按钮状态和控件种类。
- 图标类别、状态变体和显示尺寸。
- 字体用途和字号层级。
- 动效、声音与触发条件。
- 资源的季节、节庆或主题变体。
- 本地化文字的最小和最大显示长度。

制作时先做一套真实界面样板，比如背包、商店和对话页，放入实际图标和字体检查比例与阅读体验，再批量扩展其他页面。不要只单独看面板素材是否精致，还要在实际游戏缩放下检查信息密度和按钮可点性。

## 十一、需要避免的问题

- **每个系统都画一套独立风格**：使用统一基础组件，通过标题和小装饰区分用途。
- **装饰过多挤占内容**：边角纹样服务氛围，信息区域保持简洁。
- **按钮状态不明显**：同时使用形状、边框、位移或文字反馈。
- **符号太抽象**：提供文字标签和详情说明。
- **字体有味道却难读**：标题可个性化，正文与数字优先保证清晰。
- **季节换肤改变布局**：保留按钮位置和信息结构。
- **高亮效果依赖颜色**：增加符号、形状或文字提示。
- **图标和物品画风不一致**：与物品图标、地图瓦片和角色资源共用视觉规范。

## 十二、推荐实施顺序

后续进入制作或开发时，可以按以下顺序推进：

1. **确认整体视觉规范**：配色、描边、材质、字体和布局层级。
2. **制作基础组件**：面板、按钮、标签、滚动条、输入框和确认框。
3. **补充通用图标与状态符号**：覆盖背包、生产、天气、交易、任务和关系状态。
4. **实现关键页面样板**：背包、商店、对话、配方和建设界面。
5. **加入装饰与主题表现**：季节纹样、农场手账和节庆变体。
6. **检查本地化与无障碍**：验证长文本、字号、对比度和输入设备焦点。
7. **在实际游戏画面中反复检查**：确保 UI 不遮挡地图，也不会因缩放失去可读性。

优先做好基础组件、文字层级和状态图标。它们会被背包、商店、天气、任务和建造页面反复使用；这套基础稳定后，再加季节主题和装饰变化，会更容易保持整款游戏的视觉一致性。
