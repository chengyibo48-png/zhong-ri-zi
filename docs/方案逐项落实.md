## 经营、自然与成长

| 方案要求 | 实际做法 |
| --- | --- |
| 三档土壤、堆肥、轮作、剩余天数 | 地块色点、悬停提示与农田照料页；豆类/堆肥/休耕恢复；少量虫害可手工处理，不毁地 |
| 品质与空间搭配 | 普通、好收成、精心照料三档；品质随存取保存，消费优先普通；菜架、荫地、沟边菜床给予小幅帮助 |
| 简易水利与中后期设施 | 夏季水渠、蓄水桶、自动浇水、秋季小温棚；高温/台风消耗储水，寒潮仅轻微减速 |
| 家畜日常与散养 | 鸡鸭牛有名字、性格、亲近度；可改名、喂食、清理垫草、陪玩；棚舍储料，荫地散养偶有额外产物 |
| 移动布局 | 十种家具/设施，可制作、放置、撤回再放；固定草坪格保护建筑与主要通道。布局持久化 |
| 背包、分类、储物、拆分 | 背包分类、批量使用/出售；柜子按指定数量存取和整叠存取，品质一起迁移；无强制腐坏 |
| 试做发现、替代食材 | 两种食材试配，失败不扣料；学会后按标准用量制作。叶菜、鸭蛋、替代河鱼等可代用，属于普通品质 |
| 工具升级 | 锄、水壶、采集工具、鱼竿可升级减耗；斧、镰刀、布置工具纳入快捷栏，无耐久损坏 |
| 可预期的赶集经济 | 每周第 6 天需求物品 +20%，提前告知，基础价格不暴跌；配方摊、材料与米粮采购 |
| 少量季节鱼与轻采集 | 6 种河鲜，随季节及雨水变化；自动收竿或短等待；季节采集物，频繁采集的食材当日略减，次日恢复 |
| 双向邻里与关系网 | 交谈回礼、每周来信、修渠后的顺路浇水；八组亲友回应；借工具支架、代买、看摊、修菜筐等四项可延后小忙 |
| 环境小事与聚会 | 茶桌、修理摊、小戏、找画本；每周可重复，不承载唯一主线线索 |
| 四类熟练度与风格 | 农事、烹饪、手艺、交往各两选一；关键节点选择，基础操作不锁等级 |
| 图鉴、旧物、成就、陪伴宠物 | 作物、料理、鱼、动物、人物、旧物入口；六件档案线索、四种纪念物；猫狗改名与陪玩，无效率依赖 |

## 叙事、输入、音画和工程支撑

- 四章年度主线、16 周生活主题、24 节气提示、生日表和 112 行内容日历已建立。年度回顾按经营偏好、修缮、公共事务、人物故事与伴侣生成，提供三种来年意向，不以财富或收集量定优劣。
- 全屏场景、等比例跟随镜头、游戏内生活簿和可收起 HUD 保留；所有菜单暂停时间。增加大字号、高对比、逐字/即显文本、音量分组、钓鱼辅助。
- 键盘重映射、数字 1–8 工具与浏览器标准 Gamepad 输入已接入。手柄支持移动、交互、菜单导航、表单左右调整、工具切换与可关闭轻震动。**未连接真实手柄，本次没有声称完成硬件兼容验收。**
- 像素人物共用 32 像素高绘制空间、四向与步态，并有有限肤色、发型、上衣、草帽组合。24 位 NPC 采用共享动作与颜色/外观差异；新增作物图标、家具、季节工程、猫狗、鸟、雪与年度四季小画面。
- 四季琴音采用四组音列与短句，雨/风/水、日夜和区域环境层使用本地合成；音乐、环境与交互音可分别调节。这是程序化音画，尚不等于专门制作的商业音轨、逐帧角色资产和过场插画。
- 存档版本升为 3，保留旧存储键以原位迁移，支持 v1/v2。对新增背包品质、仓储、布局、人物进度、婚姻、技能、加工等字段校验；保留自动备份、三个手动档和导入导出。
- 开发服务 `node server.cjs --dev` 才加载检查台：跳日、传送、物品、关系、事件重置、状态与性能。普通服务器和离线构建不加载调试模块。存档耗时、错误和场景切换有只读诊断。
- 提供资源/授权来源说明、版本、SHA-256 清单、可重建离线文件和 ZIP 快照。完整源代码纳入本地 Git。未自动上传任何云端；异地备份目的地仍需由项目持有人指定。

## 发行层面的边界

本次把遗漏的首发系统和内容规模补成了可以操作与保存的浏览器实现，属于 **v0.3 内容扩展版**。不把程序化文字演出描述为已经完成商业美术演出，也不把模拟测试描述为真人长期平衡测试。

本次已执行 29 项逻辑测试、真实界面功能验收、保存恢复、390 像素窄屏与大字号检查。额外真实旧版夹具和构建静态校验见验收记录。内置浏览器的 URL 政策禁止 `file://`，所以 v0.3 离线包本轮只做脚本编译/资源完整性检查，未重新进行断网浏览器运行测试；此前 v0.2 的离线实测不能冒充本版验收。正式发布前仍需实际目标浏览器、手柄、音频听感、长期平衡和独立安装环境的最终复验。

原方案 O/X 项保持原范围：不加入战斗、矿洞、武器、疾病死亡、线上运营、第二年新主线、额外大地图、完整子女成长或强制生态惩罚。
