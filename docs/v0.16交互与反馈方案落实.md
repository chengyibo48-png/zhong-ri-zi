# v0.16 交互与反馈：手边的事，有了回响

日期：2026-09-27。依据用户提供的交互与反馈优化方案，并再次逐项核对完整深化说明。方案内“工作区没有可读取项目”的判断不适用于本次：实现基于当前可运行源码、现有动作系统及存档规则。

## 实际落地

| 方案方向 | 当前实现 |
| --- | --- |
| 知道能做什么 | 近距与悬停使用同一份状态说明：对象、动作、成熟度、品质数量预估、体力、材料与阻碍原因。含深耕、范围作业、饲料适配、鱼饵、加工队列、储水、营造缺料、合作社待领款。 |
| 稳定目标 | 距离、朝向、工具匹配、可操作性共同排序；保留当前目标容差；鼠标指向优先，手动切换后锁定到离开范围。键盘 [ / ]、触屏换目标、手柄 L3。切换室内坐标空间时清除选择。 |
| 过程可见 | 沿用准备、动手、收好三段动作，动作时隐藏普通提示与快捷操作。完成才结算，取消不消耗未完成步骤。普通节奏可缩至 65%，最低 0.45 秒；钓鱼判定和睡眠时长不受影响。 |
| 真正的结果 | 动作前后对比背包与仓库的合计品质数量、金额、关系以及目标田块/动物状态；分清消耗与所得，存取不伪造新获得。失败或无变化不生成成功收成。 |
| 跨系统成果 | 额外识别鱼获图鉴发现/体长纪录/放流/空竿原因、加工入队、建设开工、工具升级、待结算货单、订单交付、关系阶段及邻里约定变化。入队不等于成品已入包，代销不等于钱已到账。 |
| 克制的浮字 | 同物品同品质短时合并，明确写品质，最多三条；靠角色侧边显示，长文本截短后可在回响看全文。进入另一房间清除旧坐标浮字。可切紧凑或关闭。 |
| 分层通知 | 普通即时结果、需关注成果、照料/天气风险分别处理；同类加工完成合并。重要世界通知可点击打开回响，普通模式最多三条，不阻断操作。安静模式保留风险与重要结果。 |
| 可回看 | 游戏内“手边回响”保存最多 80 条，分类、搜索、未读与相关手记入口。保留最近七个有操作的日子，统计有实际变化的操作、收入、支出与所得品质数量。 |
| 操作保护 | 覆盖手动档前展示档案信息；读档前确认并自动保存当前状态为“读取前的回退档”。回退保存失败则中止读取。原有物品锁定、回购、布局撤销继续可用。 |
| 输入一致 | 菜单与动作锁隔离探索输入；手柄 B 可取消进行中的动作。按当前输入显示 E/A/点按；按钮空格激活不再抢先触发场景交互。 |
| 可访问性 | 5/8/12 秒文字停留，普通/紧凑/关闭浮字，舒缓/利落动作，减少动效，安静模式。减少动效降低雨雪粒子密度、关闭门口淡黑与文字漂移，保留实际动作和天气识别。沿用字号、对比度、音量、轻松钓鱼选项。 |

## 保留的体验与适配边界

- 全屏画布、所有生活模块内置、3840×3840 连续村庄、隐藏常驻小地图保持；完整地图仍可用。方案中小地图提示由完整地图与环境状态承担。
- 不增加背包格数上限。现有物品按数量与品质保存；不引入地面掉落过期或静默丢失规则。
- 日常播种、喂养、收获不增加确认弹窗。动作保留过程，不提供完全跳过。原有回购、锁定与布局撤销承担日常误操作保护。
- 回顾从本版实际记录起累计；不虚构旧档历史，不把“购买所得”称为纯收获。最近七个有操作日，不是每天强制弹窗，也不包含无操作的空白日。
- 消息记录有上限，尽量先移除已读普通结果；不是无限永久消息存储。
- 继续使用项目 Canvas 像素绘制与合成音效，本轮没有新增外部素材或虚构插件调用。
