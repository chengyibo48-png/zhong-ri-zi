# v0.10 禾溪百工手记

本轮依据同项目《优化方案》聊天中的工具与设施专项建议，结合原始乡村方案及现有种植、畜牧、小灶、营造系统实施。专项原文保存在《工具与设施系统优化方案.md》，它是设计参考，不包含对本轮操作的授权或额外指令。

## 玩家入口

生活菜单 → 工具与设施。农具间和原有工作台也打开这个页面；四时农事的设施页提供直达按钮。四个页签分别管理工具专长、范围作业、设施预览、运行总览。全部保留在游戏内，翻阅时暂停时间。

## 方案与实际功能

| 方案方向 | 本版实现 |
| --- | --- |
| 工具按用途区分 | 田垄锄、竹嘴水壶、弯刃镰刀、竹柄斧、青竹钓竿、软刷与收奶布六类。建设工具继续使用已有营造草图。 |
| 升级改变用法 | 原物 → 一阶省力 → 二阶专长；一阶锄、水壶、镰刀开放一行三格，二阶宽幅方向开放十字五格。每种工具单独记住范围和方向。 |
| 可逆的分支 | 锄头连垄或养土、水壶宽幅或顺根细浇、镰刀连畦或留种、斧头多收木竹或缩短采集、钓竿快速收线或优质鱼获、牧场工具快速照料或安抚。二阶后免费切换。 |
| 清楚的解锁 | 一阶沿用旧版资源成本与投入；二阶满足进村满一周、该工具成功使用八次、农具间完成改良中的任一条件。升级须有资金、材料、体力，实际走到农具间才执行。 |
| 范围和耗费预览 | 72 块田的双色网格和世界悬停轮廓；中心金边、适用目标绿底；预估实际体力和动作游戏时间。跳过湿田、未熟作物和不能开垦的田，不跨田区拼接范围。 |
| 动作反馈 | 角色沿现有路径逐格执行，途中可取消；沿用松土、洒水、采收、照料动作及粒子。工具图标按等级换金属、手柄颜色和标记，工具栏显示当前范围。 |
| 设施改良与维护 | 七类田埂设施可加固一级，覆盖半径增加 25%，日常和台风磨损减半。加固不免费恢复耐久；效果进入真实日结算和覆盖圈。 |
| 放置、移动、回收 | 预览费用和实际覆盖，可移动、维修、暂停、完整收起、重放。每田埂最多两座且不重复同类。回收至专用设施库，等级、耐久和开关保留；重放优先使用库内同类原件，只消耗搬运体力和时间。 |
| 自动化状态可见 | 汇总田间设施、已建畜舍、可用小灶工位。显示缺水、缺适用饲料、缺垫草、停机、待养护、待清洁、加工中、可收取、暂停和空闲；可从提醒安排角色补水、修理、清洁或收取。 |
| 跨系统联动 | 养土进入原土壤肥力和板结；留种继承品种并避免与自动留种重复；鱼获进入四档品质库存；牧场专长修改真实清洁/收取动作；畜舍与厨房仍由各自权威规则执行。 |

## 适配取舍

继续保留手持工具不损坏的轻松玩法；只有原本就有维护需求的田间设施和畜舍使用耐久。没有新增另一套随机工具品质抽取或重复材料门槛，功能进阶由两阶和专长承担。当前没有矿洞，因此不添加空用途的镐；钓鱼采用时间与鱼获品质分支，保留已有控鱼小游戏。营造系统已支持布局、旋转、回收、仓储和建筑分支，继续使用它，避免第二套建筑放置规则。范围作业采用选择模式及逐格步行动作，没有改成蓄力瞬间扫完一片田。

## 存档与模块

仍使用 v3 主存档，新增 toolkit.version = 1。已有 hoe/water/rod/gather 升级自动继承，旧 gather 一次投入同时继承到镰刀、斧头一阶，二阶分别改良。既有背包、品质、设施、畜舍、厨房队列、房屋工程不重置。非法等级、范围、库存设施耐久会拒绝载入。

- src/tools.js：工具规则、范围计划、实际动作联动、设施事务、状态总览和迁移。
- src/tools-view.js：六类像素工具、等级变化、田间范围与设施提示。
- src/tools-ui.js：百工手记、预览、专长及实体操作入口。
- 新脚本遵循原系统加载顺序；独立成品包含 27 段内嵌脚本。

## 验证

149 项规则测试通过：原有 124 项回归加 25 项工具设施专项。专项覆盖成功动作计数、解锁替代条件、精准浇水、深耕、原品种留种去重、木竹收益与耗时、鱼获品质、牧场专长、真实灌溉覆盖、磨损、移动回收重放、存档校验、失败不扣料以及 225 天跨系统读写。

浏览器在独立 4174 开发存档验收：五格补水、跳过湿田、喷灌加固（覆盖 10 → 13 格）、回收后重载、重放到相邻田埂（保留加固和耐久 18，零材料）、角色沿路去农具间改良、免费切换专长、由总览走到小灶清洁（20 → 100）。390px 宽度下页面和 48 格东坡网格无横向溢出且可点选。

正式成品通过资源与内嵌脚本检查；HTTP 直接载入独立 HTML 验证旧玩家。没有声称完成实际断网双击、实体手柄或长期真人平衡验收。测试开发场景不进入独立成品。
