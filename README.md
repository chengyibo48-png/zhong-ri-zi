# 种日子

中式乡村像素生活游戏，交互与反馈深化版 v0.16.0。单人单机、无战斗。方案原文、本轮七项要求和验收记录随源码保存。

## 开始游玩

使用 Chrome 或 Edge 打开同目录的 **种日子.html**。独立文件内嵌全部代码、像素绘制和音频合成，不需要安装引擎或下载依赖。本次 v0.16 已完成单文件构建、资源检查和 HTTP 下直接加载成品验证；内置浏览器限制 file:// 导航，尚未重复实际断网启动验收，历史版本离线测试不代表本版实测。

数据保存在当前浏览器和地址下。换浏览器、移动文件或清理数据前，通过右上角“存档”导出 JSON。独立文件、本地预览与不同端口的存档彼此独立。v1/v2/v3 旧档可迁移到 v4，沿用原存储键自动识别已有进度。

开发预览运行 `node server.cjs`，访问 http://127.0.0.1:4173 。无需 npm install。

## 第一段生活

1. 收获小院成熟的青菜，到厨房做清炒时蔬。
2. 从“邻里心愿”给阿婆送菜，再认识其他邻居。
3. 到竹林采木料和竹材，修好村口河埠，看到村庄改变。
4. 阅读信箱，按时令选种子，逛集市，随时翻“故事与这一年”。
5. 关系页会告诉你下一段故事需要什么。没有必须每天赶上的进度。

## 制作边界

这是补齐主要系统和内容规模的可玩版本，尚不等同正式商业首发。剧情为短篇文字选择场景，美术和音乐由代码生成；仍需真人长期平衡、剧情润色、专属美术音频制作、实体手柄和目标设备兼容验收。联机、战斗、矿洞、完整子女成长和额外地图不在当前范围。

技术采用原生 JavaScript + Canvas，不是 Godot 工程或 Windows EXE。方案将 Godot 列为优先候选，并未强制绑定。本目录可整体复制到任意可写文件夹；无远程资源和运行时依赖。


- `node tests/environment.test.cjs`：33 项天气与自然动作专项，覆盖跨日预报、设施缓解、生产保鲜、旧档、225 天联动和轨迹/站位/取消。

- `node tests/forage.test.cjs`：28 项采集、地图迁移、围栏路线与存档专项。
- `node tests/fishing-interiors.test.cjs`：34 项水域、钓鱼过程、鱼获利用、独立室内布局与家具通路专项。

- `node tests/npc.test.cjs`：35 项邻里作息、面对面交互、情境对话、小事选择、历史记录和长期存档专项。
